## 모듈 연결 후 업그레이드 효과

**📚 지식 활용 (wiki_manager)**
지금: Gemma 기본 지식만 사용
연결 후: 내 옵시디언 노트를 실시간으로 참조

**🎯 답변 품질 (cognitive_engine)**

연결 후: 법률질문/코딩질문/일반질문 자동 감지해서 톤 조절
→ 할루시네이션 줄고 전문성 올라감

**🗂️ 자동 정리 (ingest_engine)**
지금: 수동으로 파일 정리
연결 후: 텔레그램으로 링크/파일 보내면 자동으로 옵시디언 분류
→ 지식 관리 자동화

**⚡ 시스템 제어 (executor)**
지금: 불가능
연결 후: 텔레그램으로 맥 명령어 실행 가능
→ 출장 중에도 집 맥 제어
