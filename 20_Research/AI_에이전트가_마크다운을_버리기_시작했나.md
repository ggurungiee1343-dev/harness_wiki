## 핵심 논점

### 마크다운의 한계
- 사람이 결과를 안 읽음 (처음 몇 줄만)
- AI가 강해질수록 사람은 더 적게 판단
- **블랙박스화 위험**

### HTML이 나은 이유
| 마크다운 | HTML |
|----------|------|
| "이렇게 했다" | "이렇게 이해하면 된다" |
| 기록에 강함 | 판단에 강함 |
| 텍스트의 벽 | 비교/대비/색상/공간 활용 |

### 비용 vs 집중력
- HTML 생성: 마크다운보다 **2~4배 더 많은 토큰**
- But: **토큰보다 사람의 집중력이 더 비쌈**
- 진짜 문제는 사람이 결과물을 안 읽는 것

### Claude Code 사례
- PR 설명서 → diff 옆 색상 주석
- 설계안 → 인터랙티브 맵
- 문서 → 조작하는 화면 (컨트롤 타워)

### 미래 예측
> "AI가 만든 결과물의 진짜 가치는 생성되었는가 아니라, 사람이 판단할 수 있는가에서 나온다"
