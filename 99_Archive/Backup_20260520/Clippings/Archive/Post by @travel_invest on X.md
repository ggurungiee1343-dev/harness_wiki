🚨 “SpaceX는 이제 로켓 회사가 아니다” 🔥

SpaceX가 실제로 하는 5가지 사업:

• 발사 회사 → 3.5개월 만에 위성 1,000기 발사 (하루 1기)

• 연결 회사 → Starlink 10,200기 운영, 전 세계 최대

• 컴퓨트 회사 → Colossus 22만 GPU + 1,190억 달러 테라팹

• 모델 회사 → Grok, 모든 벤치마크 1위

• 화성 회사 → Starship + 10년 내 화성 정착 목표

다섯 회사가 하나로 움직인다.

경쟁자는 없다.

엘론이 말한 “2등을 보려면 제임스 웹 망원경이 필요하다”는 바로 이거였다 😱
