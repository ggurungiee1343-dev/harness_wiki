# 🧠 Karpathy의 CLAUDE.md 규칙 분석 및 헤르메스 적용 방안

**작성일:** 2026-05-21  
**기반 문서:** Andrej Karpathy의 AI 코딩 가이드라인 (CLAUDE.md 바이럴 트레드)

## 📌 1. 핵심 내용 요약
인공지능 대가 안드레 카파시(Andrej Karpathy)와 AI 개발자들이 정립한 `CLAUDE.md` 사상은 **"AI 에이전트가 매 세션마다 제로 상태에서 추측해서 코딩하는 것을 방지하고, 프로젝트의 원칙과 지식 맥락을 컨텍스트로 상시 강제하는 법"**을 다룹니다. 이를 통해 AI 코딩 정확도를 **65%에서 94%까지 극대화**시켰습니다.

핵심 규칙은 크게 4가지 영역으로 나뉩니다:
1. **인터페이스 필터 (Kill the filler):** "좋은 질문입니다!" 같은 미사여구를 배제하고 즉시 본론으로 대답하여 토큰 절약.
2. **행동 제어 (Stay in scope):** 무관한 코드나 파일을 리팩토링하지 않고 지정된 범위만 수정. 파괴적인 행위 전 강제 확인.
3. **기억 유지 (Memory Logs):** `MEMORY.md` 의사결정 로그와 `ERRORS.md` 실패 분석 로그를 유지해 이전 세션의 교훈 유지.
4. **카파시의 4대 규칙:**
   - **질문하라(Ask, don't assume):** 모호하면 추측하지 말고 코딩 전에 물어볼 것.
   - **가장 단순한 솔루션(Simplest solution first):** 오버엔지니어링 금지.
   - **무관한 코드 불간섭(Don't touch unrelated code):** 요청하지 않은 코드 수정 금지.
   - **불확실성 명시(Flag uncertainty):** 모르는 사실은 추측하지 말고 솔직히 고백할 것.

## 🔍 2. 현재 헤르메스(Harness) 시스템과의 비교 분석

놀랍게도 **현재 박사님의 헤르메스 시스템은 이미 이 트렌드의 핵심 철학을 한발 앞서 완벽하게 이식하여 운영 중**입니다.

| Karpathy 제안 가이드 | 헤르메스(v3.9) 구현 상태 | 평가 및 분석 |
| :--- | :--- | :--- |
| **`CLAUDE.md` 컨텍스트 자동화** | `hermes_context_builder.py` 및 계층적 `HERMES.md` 로더 탑재 완료 | **우위:** 우리는 단일 파일이 아니라 루트와 각 폴더별 계층적 `HERMES.md` 규칙을 동적으로 수집해 주입하므로 훨씬 정교함. |
| **`MEMORY.md` 결정 이력** | `hot.md` 및 `harness_memory.json` | **유사:** 최근 변경사항과 대화 이력을 상시 공유 버퍼로 관리 중. |
| **`ERRORS.md` 실패 복구 로그** | `executor.py` 및 `skill_evolver.py` | **우위:** 우리는 에러 발생 시 자율적으로 대체 명령을 수행하고 복구에 성공하면 `SKILL.md`로 자동 기록하여 학습 및 캐싱함. |
| **인사말 배제 (No filler)** | 프롬프트 가이드라인 내장 | **유사:** 불필요한 서두를 생략하도록 프롬프트에 정의되어 있음. |

## 🚀 3. 헤르메스 시스템에 추가 적용 및 고도화할 과제

우리의 우수한 아키텍처에 카파시의 실전 가이드라인을 더 정교하게 결합하기 위해 다음 사항들을 적용합니다.

### 1) 카파시 4대 원칙의 명문화 (`modules/HERMES.md` 이식)
헤르메스가 코드를 수정하거나 스크립트를 작성할 때 카파시의 4대 원칙을 최우선 행동 강령으로 인지하도록 `modules/HERMES.md`에 규칙으로 이식합니다. (수행 완료)

### 2) "질문 및 옵션 제시 후 승인 받기" 강화
* 복잡하거나 파괴적인 행위(예: 파일 삭제, 대규모 이관, 외부 API 연동 등) 직전에 헤르메스가 **2~3가지 대안을 제시하고 박사님의 선택을 기다리는 롤백 가드레일**을 시스템 프롬프트 및 `verification_engine.py`에 적용합니다.

### 3) 불필요한 미사여구 제거 규칙 추가
* LLM 응답 시 문맥상 의미 없는 "물론입니다!", "좋은 질문입니다!" 등의 웜업 문장을 배제하도록 시스템 프롬프트 가이드라인을 보강합니다.
