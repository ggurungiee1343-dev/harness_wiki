## 1. 농사매매 철학

### 핵심 정의
> "세력이 있는 종목이 개미털기를 마치고 이제 막 다시 올라가기 시작할 때 매수하는 것"

**왜 농사매매인가:**
- 세력이 고의적으로 주가를 하락시켜 개인 손절 유도 (개미털기)
- 개인 손절 물량을 세력이 받아먹음
- 개미털기 완료 후 상승 전환 시점에 진입
- 결과: 승률 높음 + 손익비 높음 (손절가 명확)

**예외:** 시장 하락장이면 세력도 못 올림 → 시장 필터 필수

### 매매 목표 수치
- 성공: +10~15%
- 실패: -3% 손절 (반등선 기준)
- 손익비: 약 1:4~5
- 월 거래 종목: 5~10종목만 (정확한 타점에서만)

### 핵심 원칙
```
차트가 기준. 수급과 재료는 거들 뿐.

추돌이 미완성 = 절대 매수 금지
"추돌이 완성 안 되었는데 사면 세력들이 혼내준다"

추돌이 후 3일선 이탈하지 않으면 주도주는 결국 슈팅이 나온다.

최강 조합: 역사적 신고가 종목 + 15일선 추돌이
```

## 2. 핵심 용어 사전

| 용어 | 정의 |
|---|---|
| **추돌이** | 추세를 돌리는 자리 = 손익비 + 추세추종 동시 충족 타점 |
| **농싸** | 주가 하락 중 세력 하락매집 신호 |
| **세력평단 (C2)** | 거래량 가중 이동평균(VWMA). 세력의 실질 매매단가 추정선 |
| **반등선 (DD)** | 급등 종목이 높은 확률로 반등하는 중간값. 손절기준선 |
| **자석신호** | 볼린저밴드 폭 수축 → 세력 매집 완료 신호 |
| **슈팅발판** | EMA45/100/200선에서 지지 후 슈팅이 나오는 타점 |
| **삼위일체** | 차트 + 수급 + 테마(실적) 3가지 모두 좋은 종목 |
| **A급 타점** | EMA정배열 + DD<EMA20 + DD/EMA20 동시 돌파 |
| **삼돌이** | 역배열 EMA20/40/80 동시 돌파 + 거래량 |
| **수급주도주** | 주도주 중 외국인+기관 쌍끌이 매수가 들어온 종목 |
| **단기 추돌이** | 15일선 이내 추돌이 |
| **중기 추돌이** | 45일선 추돌이 |
| **장기 추돌이** | 200일선 추돌이 |

## 3. 기법별 분류 체계 (✅ 최종 확정)

### 3-1. 농사 기법 3종
```
1. 턴어라운드 농사
   - 조건: 주봉 EMA20/40/80 역배열 → 추돌이
   - 진입: 200일선 N자 돌파 전 수동 분할매수
   - 손절: 주봉 반등선(n=26) 이탈
   - ⚠️ 자동매매 부적합 → 수동 분할매수만
   - ⚠️ 수급조건 20개 필요 → 키움 구현 어려움, LS증권으로 확인

2. 신고가 농싸
   - 조건: 일봉 45>15>150>200 역배열 → 추돌이
   - 진입: 45일선 추돌이 타점
   - 손절: EMA195(15일선) 이탈
   - ✅ 자동매매 적합

3. 주도주 농사
   - 조건: 15>45>100(150)>200 정배열 → 추돌이
   - 진입: 3일선 또는 15일선 추돌이
   - 손절: 3일선(EMA39) 이탈
   - ✅ 자동매매 적합
```

### 3-2. 이평 배열 기준 분류 (✅ 확정)
```
주도주 농사: 15>3>45>150>200
신고가 농싸: 45>1>3>15>150>200
턴어라운드:  장기이평 역배열 돌파 (수동)

자동매매 적합: 주도주농사 + 신고가농싸만
자동매매 부적합: 턴어라운드(분할매수), 단타(직접매매 승률 더 높음)
```

### 3-3. 추돌이 분류 (✅ 확정)
```
단기 추돌이: 15일선 이내
중기 추돌이: 45일선
장기 추돌이: 200일선

"모든 기법은 추돌이 기반. 다 같은 기법이다."
```

### 3-4. 추돌이 vs 전고돌파 비교 (✅ 확정)
```
전고돌파:
  - 세력 개미털기 자리 → 스윙 승률 낮음
  - 단타 영역

추돌이:
  - 개미털기 완료 후 돌파 → 스윙 승률 높음
  - 돌파매매자 + 눌림매매자 동시 매수 → 매수세 강함

최강 추돌이 조건:
  "3일선이 15일선 바로 위 + 주가가 15일선 아래→15일선+3일선
   연달아 돌파 + 일봉 장대양봉"
  → 15일선 위 골든크로스 > 15일선 밑 골든크로스 (매물 적음)
```

### 4-3. 반등선 수식 (DD) (✅ 확정)

```
일봉/주봉 반등선:
  D1 = if(highest(close,n)>highest(open,n), highest(close,n), highest(open,n))
  D2 = if(lowest(open,n)>lowest(close,n), lowest(close,n), lowest(close,n))
  DD   = 0.5*(D1+D2)         ← 차트 표시용
  DD_S = 0.382*D1+0.618*D2   ← 신호 계산용 (더 보수적)

분봉반등선 (✅ 농사단타 수식 확정):
  A = if(PreDayClose() > DayLow(), DayLow(), PreDayClose());
  B = DayHigh();
  0.5 * (A + B)
  "전일 종가와 당일 저가를 고려한 반등타점"

타임프레임별 n값 (✅ 확정):
  일봉:    n=26
  주봉:    n=26
  30분봉:  n=278
  5분봉:   n=338 (1일 반등선, 보라색)
  5분봉:   n=234 (3일 반등선, 검은선)
```

### 4-8. 농사단타 전용 신호 수식 (✅ v4 신규)

```
5일 신고가 신호 (◆ new!):
  highest(c, 390) <= h
  and c(1) < c
  "세력의 등장 신호. 5일 신고가 후 눌림 = 신이 주신 기회"

50억봉 신호:
  c(1) * 1.01 < h and h >= 0
  and 거래대금 >= 5000 (백만원)
  "5분봉 50억 거래대금 + 5일신고가 = 매우 높은 확률로 세력 등장"

매수신호 (↑):
  a  = sum(crossup(c, bollinger_up((c+h+l)/3, 3.5, 33, 단순이평)));
  a1 = (a-a(20))>=1 and eavg(c,20)*(100+등락)/100>=가격
       and eavg(c,20)*(100-등락)/100<=가격;
  a11= (a-a(20))>=1 and eavg(c,5)*(100+등락)/100>=가격
       and eavg(c,5)*(100-등락)/100<=가격;
  a2 = (a-a(20))>=1 and crossup(c,highest(c,20,1)) and v(1)<v;
  a22= (a-a(20))>=1 and crossup(c,highest(c,5,1)) and v(1)<v;
  a3 = eavg(c,5)>eavg(c,20) and eavg(c,20)>eavg(c,60)
       and eavg(c,5)>eavg(c,120);
  a4 = o<=c and c*v>=50000000;
  x  = ((a1 or a11) or (a2 or a22)) and a3 and a4;
  x and x!=x(1)
  변수: 등락=1(정수형), 가격=종가(가격형)
  "눌림목 타점 조언. 이게 떴다고 무조건 매수 아님"
  실제 매수타점: 노란선(VWMA78) 또는 반등선

더블화살표 (돌파 신호, ✅ 확정):
  A1 = Bollinger_Up(C, 2, 300, 단순이평);
  B1 = envelope_Hi(C, 300, 6/100);
  M  = (highest(high,200) + lowest(low,200)) / 2;
  (crossup(c,a1) or crossup(c,b1) or (c>a1 and c>b1))
  and M
  and MA(V, 20, 지수이평)
  and crossup(c,(predayhigh()+predaylow()+predayclose())/3
                +predayhigh()-predaylow())
  의미: BB상단/엔벨로프상단 돌파 + 200봉중간값 + 전일피벗 돌파
```
