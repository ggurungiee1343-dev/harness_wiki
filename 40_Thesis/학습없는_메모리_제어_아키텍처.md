# 학습 없는 메모리 사용을 위한 제어 아키텍처

> **논문**: A Control Architecture for Training-Free Memory Use
> **저자**: Yanzhen Lu (Shanghai Qizhi), Muchen Jiang (Nanjing Whale Cloud), Zhicheng Qian (Southeast Univ.), Xingyu Zhou (Xiamen Univ.)
> **arXiv**: 2604.18206

---

## 개요

프롬프트 주입 메모리는 모델 가중치 업데이트 없이 추론 능력을 향상시키지만, **검색된 내용이 올바른 상태에서 적용되어야 한다**는 제어 문제를 야기한다. 본 논문은 이 문제를 **적용 가능성 제어(applicability control)** 로 정식화하고, 학습 없이(training-free) 메모리를 제어하는 아키텍처를 제안한다.

## 핵심 기여

### 1. 적용 가능성 제어 프레임워크
- **언제** 메모리 보조 2차 패스를 트리거할 것인가?
- **언제** 메모리 조건부 답변을 신뢰할 것인가?
- **어떤** 메모리 뱅크(규칙 vs 예제)를 노출할 것인가?
- **시간에 따라** 메모리 뱅크를 어떻게 유지/관리할 것인가?

### 2. 4가지 메커니즘

| 메커니즘 | 역할 | Hermes 대응점 |
|---|---|---|
| **Uncertainty Routing** | 언제 메모리 보조 패스를 트리거할지 결정 | hybrid_router 우회 경로 |
| **Confidence Selection** | 메모리 조건부 답변의 신뢰도 평가 | session_search 정확도 임계값 |
| **Bank Selection** | 규칙 vs 예제 뱅크 중 선택 | ingest 분류 정확도 |
| **Evidence Governance** | 시간에 따른 뱅크 품질 관리 | TagLinker + DB 동기화 |

### 3. 실험 결과 (compute-matched)
| 벤치마크 | Δ (vs baseline) |
|---|---|
| SVAMP | **+7.0점** |
| ASDiv | **+7.67점** |
| QA tasks | 소폭 긍정적 |
| Agent tasks | 소폭 긍정적 |

### 4. 주요 발견
> **메모리 자체보다 제어 아키텍처가 개선을 주도한다.**
- 신뢰도(confidence)가 도움이 되는 규칙과 해로운 규칙을 분리
- 고정 검색 하에서, 복구 vs 손상 차이는 검색된 집합에 실제 편집된 항목이 포함된 행에 국한됨

## Hermes 시스템과의 연관성

### 직접 적용 가능 포인트

1. **Session_search에 Confidence Selection 적용**
   - 검색 결과가 모호할 때 **기권(abstain)** 또는 **fallback** 결정
   - 현재: 무조건 가장 관련성 높은 결과 사용 → 신뢰도 임계값 도입

2. **Ingest 분류에 Uncertainty Routing 적용**
   - 불확실한 분류 결과는 수동 검토 대기열로 라우팅
   - 현재: LLM 분류 결과를 무조건 신뢰

3. **Bank Selection 개념**
   - 규칙(rule) 메모리 = 시스템 문서/설정
   - 예제(exemplar) 메모리 = ingest된 논문/참고자료
   - 태스크 유형에 따라 다른 뱅크 선택
