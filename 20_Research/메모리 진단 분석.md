### 🎯 1순위 원인: **File-backed cache 16.9GB!**

macOS는 디스크 I/O를 줄이기 위해 **파일을 읽으면 자동으로 메모리에 캐싱**합니다. MJ님의 Obsidian Vault(~12만개 MD 파일 추정)와 Python 라이브러리들이 이 캐시를 가득 채운 겁니다. **36GB 중 16.9GB를 순수 파일 캐시가 점유!**

### 🎯 2순위 원인: **Compressed Memory 8.1GB & Swap 3GB**

압축 메모리가 8.1GB나 차지하고 스왑까지 3GB 사용 중 → **이미 메모리 압박이 심각한 상태**입니다. 압축/해제 오버헤드로 CPU도 같이 느려지는 중.

### 💡 이제 해결 방안 — 3단계 전략

**1️⃣ 즉시 효과 (30초): File-backed cache flush**
```bash
sudo purge
```
→ 16.9GB 중 대부분 회수 가능. 단, 일시적이며 다시 차오름.

**2️⃣ 중기: Fat Harness 다이어트** ← MJ님이 말씀하신 그거!
- **hermes-tool-slimmer** 적용 → Hermes Agent 툴 스키마를 60~80% 축소
- Tool 스키마가 줄면 context 크기 감소 → LLM 호출 시 KV 캐시 부담 ↓
- busyBee-cpu 접목 → 96%의 뻔한 결정은 30ms CPU 처리로 LLM 호출 급감

**3️⃣ 구조적: Hermes Agent.app + venv 통합**
현재 `Hermes Agent.app`(158MB) + `hermes-agent venv`(411MB) = 569MB가 **중복**으로 떠 있어요. WebUI만 쓴다면 Hermes Agent.app은 안 띄워도 됩니다!
