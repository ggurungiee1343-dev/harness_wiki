**최종 한국어 번역 완료**

아래는 사용자가 제공한 전체 분석 프레임워크를 **명확하고 자연스러운 한국어**로 번역한 버전입니다. 경영진·연구자 수준의 전문성을 유지하도록 다듬었습니다.

---

### 1. 경영진 요약 (Executive Summary)
**모든 출처를 종합 분석한 후 다음과 같은 내용으로 경영진 요약을 작성하세요:**
- → 주요 발견
- → 핵심 통찰
- → 결론
- → 실질적 함의
- → 실행 가능한 권고 사항

**출력 스타일**: 경영진 청중을 위한 명확하고 간결하며 전문적인 언어로 작성.

---

### 2. 핵심 통찰 추출 (게임을 바꾸는 아이디어들)
출처에서 가장 중요한 **10가지 발견**을 식별하고, 각 항목에 대해 다음을 설명하세요:
- → 왜 중요한가
- → 어떤 증거가 이를 뒷받침하는가
- → 실제 세계에서 어떻게 적용할 수 있는가
- → 어떤 영향을 미칠 수 있는가

---

### 3. 모순 분석 (Contradiction Analysis)
모든 출처를 비교하여 다음을 식별하세요:
- → 모순되는 내용
- → 의심스러운 가정
- → 방법론적 약점
- → 정보 공백
- → 추가 검증이 필요한 부분

**가장 신뢰할 수 있는 출처**를 지목하고 그 이유를 설명하세요.

---

### 4. 비교 매트릭스 (Comparative Matrix)
다음 항목을 포함한 비교 테이블을 작성하세요:
- → 연구 목표
- → 방법론
- → 주요 결과
- → 장점
- → 한계
- → 추천 적용 분야

**어느 출처가 가장 높은 실무적 가치를 제공하는지** 강조하세요.

---

### 5. 가설 생성 (Hypothesis Generation)
제공된 증거를 바탕으로 다음을 제안하세요:
- → 새로운 가설
- → 연구 질문
- → 미탐구 영역
- → 가능한 실험 설계
- → 미래 기회

**잠재력이 가장 높은 아이디어**를 우선순위화하세요.

---

### 6. 실행 계획 (Implementation Plan)
분석 결과를 실무 실행 계획으로 전환하세요. 다음을 포함:
- → 목표
- → 구체적인 실행 단계
- → 필요한 자원
- → 위험 요인
- → 성공 지표
- → 제안 타임라인

---

### 7. 지식 평가 (Knowledge Assessment)
다음 내용을 생성하세요:
- → 20개의 도전적인 질문
- → 정답
- → 상세 설명
- → 적용 기반 질문
- → 비판적 사고 질문

각 질문에 **난이도 수준**을 표시하세요.

---

### 8. 지식 구조화 (Knowledge Structure)
모든 정보를 계층 구조로 정리하여 **텍스트 기반 마인드맵** 형태로 제시하세요:
- → 주요 개념
- → 하위 주제
- → 관계
- → 의존성
- → 교차 기능 아이디어

---

### 9. 전략적 기회 (Strategic Opportunities)
다음 항목을 식별하고, **영향력과 실행 용이성**에 따라 순위를 매기세요:
- → 상업적 응용 가능성
- → 미개척 틈새 시장
- → 해결되지 않은 문제
- → 경쟁 우위 요소
- → 수익화 기회

---

### 10. 종합 마스터 리포트 (Master Report)
위의 모든 분석을 통합한 **최종 보고서**를 작성하세요. 포함 항목:
- → 경영진 요약
- → 핵심 통찰
- → 모순 분석
- → 권고 사항
- → 실행 계획
- → 다음 단계

**학습, 업무, 의사결정에 바로 활용할 수 있는 수준**으로 완성도 있게 작성.

---
