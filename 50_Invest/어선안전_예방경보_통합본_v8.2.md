# 어선용 지정형(ID/구역) 해양안전 예방경보 시스템 — 마스터 통합본 v8.2

> **v8.2 개정 성격 (완전판·발췌용 마스터)**: v8.1(오류정정·GPS정합성) 위에 2026-07-07 예비 선행조사 결과를 통합했다. 추가된 것: (6) 최근접 선행기술 **US2010/0253547A1** 발견·반영, (7) **제1원리 기반 근본 신규성** 논거("송신 vs 지각+증명"), (8) **폐루프 발현검증(무센서)**·부인방지 로그. 본 문서는 모든 내용을 담은 마스터이며, 변리사 제출용 발췌본은 별도 `발명제안서` 문서를 사용한다.

## 0. 개정 이력 (최우선 필독)

### 0.1 인용 특허 재검증 (실재 확인, 환각 없음)
v6~7 계보의 허위 오인용 3건(US2024/0185567A1·CN206611428U·CN108961839A)은 v7에서 전량 삭제됨. v8.0이 제시한 KR101388608B1·EP2688052B1·KR20140026994A는 Google Patents 원문으로 **실재 확인**. 단 이는 정식 FTO를 대체하지 않음.

### 0.2 KR101388608B1 묘사 정정
선행특허를 "단순 사이렌"으로 묘사한 것은 오류 — 이 특허는 **이미 합성 음성 방송**이며 "3분 후 재방송"까지 있음. "음성 vs 사이렌" 차별 논리 폐기.

### 0.3 청구항 설계 오류 정정
상용 부품 품번(STM32 등)·수치를 독립항에 박으면 권리 축소 → **독립항은 기능·구조**, 부품·수치는 종속항/실시예로.

### 0.4 미검증 수치 제거·라벨링
"도달율 100%"(물리적 불가) 삭제, "공제 7.5%·입찰가·원가"는 추정 라벨.

### 0.5 GPS 모듈 정합성 정정
GPS는 필요·정합(지오펜스 자기판별 + 경보 후 반응감시)하나, "조업 상태 추정"이라는 표현은 자기원칙과 충돌 → "경보 수신 직후 좁은 시간창 내 항적 반응 모니터링"으로 재서술, 속도격상은 종속항.

### 0.6 (신규) 최근접 선행기술 US2010/0253547A1 발견
"DSC 구역호출 + 자동 채널전환 + 음성 전달"을 이미 공개한 미국 출원공개공보(2009 출원, 2012 포기)를 발견. **자동채널전환·음성 중계는 단독 신규성이 없음** → 신규성 무게중심을 "수신전용 + 다중구역 강제 + 폐루프 발현검증 + 위변조 로컬로그 + 항적격상의 결합"으로 이동(3·4장).

### 0.7 (신규) 제1원리 근본 신규성 + 폐루프 발현검증
US2010과 본 발명은 개량 관계가 아니라 **다른 문제**를 푼다: "송신 보장"(US) vs "지각+증명 보장"(본 발명). 폐루프 발현검증은 **새 센서 없이** 앰프 구동전류(발현) + GNSS 항적(반응)으로 구현하고, HSM 서명 부인방지 로그로 증명한다(3장).

### 0.8 (신규) 일본 특허 J-PlatPat 정식 검색 — 위협 없음 확인 (2026-07-08)
J-PlatPat 공식 DB에서 4개 키워드 조합(총 8건 원문 대조)으로 재검색한 결과, 본 발명의 핵심 결합과 겹치는 일본 특허는 발견되지 않음. 근접 후보 3건(JRC 위치정보배포, NYK 육상관제 통합관리, 히로세 지오펜스 계산알고리즘)은 각각 트리거·전달경로·검증·로그 4축 모두 비겹침으로 확인(17장). 전수조사는 아니므로 FTO 시 재검색 필요.

## 1. 배경 및 발상

마을 방송 안내 단말기(무선 수신기+시계)는 노년층이 조작 없이 벽에 걸어두면 방송·시계·날씨를 자연히 인지하는 앰비언트 설계가 핵심이다. 이 철학을 연안·근해 소형 어선(고령 1~2인 조업선)에 적용해, 조작이 필요한 계기판(MFD)이 아니라 **걸어두면 필요한 안전정보만 강제로 청취·인지되는 수신 전용 단말기**를 제안한다. VTS의 VHF-DSC 구역/개별 안전호출을 수신전용으로 받아 (a) 갑판·기관실 스피커·경광등 강제구동, (b) 후속 통화채널 자동전환으로 관제사 육성 중계, (c) 경보 발현을 검증·기록한다. 송신 기능 없음.

## 3. 제1원리 기반 근본 신규성 (핵심 논거)

두 발명을 더 이상 쪼갤 수 없는 근본 원리까지 분해하면 **서로 다른 문제를 푸는 관계**다.

| 근본 축 | US2010/0253547A1 (2009, 아날로그) | 본 발명 |
| :-- | :-- | :-- |
| 지능의 위치 | 발신자 (수신 무전기는 튜닝·재생만) | 수신자/엣지 (판별·구동·검증·기록) |
| 신호 모델 | 일방 push (브로드캐스트) | 수신 + 로컬 자율동작 |
| 보장 대상 | **송신** — "구역에 보냈다" | **지각 + 증명** — "대상이 지각했고 입증 가능" |
| 검증 루프 | 없음 (개루프) | **폐루프** (발현검증 + 항적반응) |

**핵심 명제**: "송신 ≠ 지각 ≠ 증명 가능한 지각"은 물리적으로 다른 층위. US2010은 1층(송신)에서 멈췄고, 본 발명은 2층(지각)·3층(증명)을 물리적으로 구현한다.

**폐루프 지각검증 (최신·저비용·무센서 원칙)**:
- **발현 검증** = 기존 스피커 구동회로 전류·부하 되먹임으로 "실제로 울렸는지" 확인(새 센서 불요).
- **반응 검증** = GNSS 항적 반응으로 "사람이 반응했는지" 확인.
- **증명** = 위 결과를 HSM 루트 기반 위변조 방지 로그(부인방지)로 봉인.
- (선택) 음압센서 병용으로 "소음 위 가청" 검증하는 변형 — 프라이버시·원가상 선택적 종속항으로만.

이 폐루프·증명 계층은 발신 측 개루프 push인 US2010이 **구조적으로 도달 불가**하며, 2009년 당시 없던 엣지 검증·암호학적 부인방지 개념에 기반한다.

## 4. US2010/0253547A1 상세 대비 — 차이점 분류

**(A) 겹침 (신규성 없음)**: DSC 구역지정 / 무전기 자동튜닝 / 튜닝 후 음성전달 — 3가지 모두 US2010에 있음.

**(B) US2010에 없는 것 (살아있는 차별점)**: 갑판·기관실 다중구역 강제방송 / 폐루프 발현검증 / 위변조 로컬 발현로그 / 항적 무변화 격상 / 위험판정 발신측 한정.

**(C) 청구 카테고리**: US2010 = 발신 측 "방법(프로세스)". 본 발명 = 수신 측 "장치". 카테고리가 달라 직접 침해는 약하나, 개시내용이 "자동튜닝+음성수신"을 드러내므로 이를 독립항 핵심으로 삼으면 신규성 부정 위험 → (B)의 결합을 독립항 핵심으로, 자동채널전환·음성중계는 종속항으로.

| 분류 | 선행특허 (실제) | 본 발명 | 유효성 |

## 7. 논리적 모순 해결

### 7.1 항적 판정과 관제소 책임 — 이중 레이어 트리거 (GPS 정합성)
위험 존재 여부(risk judgment)는 **전적으로 VTS 책임**. 단말기는 조업 여부를 판단하지 않고 GPS로 (1) 지오펜스 자기판별(수신필터), (2) 경보 수신 직후 좁은 시간창(예:300초) 내 항적 변화 유무만 기계적으로 감지 → 무변화면 격상. "조업 상태 추정" 아님.

### 7.2 수신전용 ACK — 무송신 폐루프(Zero-Tx Closed Loop)
단말기는 송신 안 함. 선원이 반응해 변침·증속하면 **기존 V-PASS/AIS**가 항적을 (평소처럼) 송신, VTS가 이를 연산해 "수신·대응 완료"를 암묵 역판정(Implicit ACK). 위치원 이중구조: 자체 GPS(로컬 자율) vs V-PASS(VTS측 ACK).

### 7.3 ITU-R M.493 자동 채널전환 중복성 소거
M.493상 자동전환 사양은 이미 존재. 대형 상선은 항해사 상시대기 전제로 자동전환을 끄거나 수동승인. 본 발명은 조타실 비운 **무인 브릿지**를 위해 무조작 채널전환 + 갑판·기관실 강제구동을 결합 — 단, 이 요소(음성중계)는 US2010 공개로 종속항 배치.

## 8. 특허 청구범위 (초안 — 변리사 검토 전제)

**【청구항 1】(독립항)**
해상 교통관제국(VTS)으로부터 수신 전용 무선 채널을 통해 하향 전달되는 안전 예방경보 데이터 패킷을 처리하는 선박용 안전 경보 장치로서, 무선 송신 회로가 물리적으로 배제되어 수신 전용으로 구성되고; 채널70 DSC 지리적 구역호출 또는 개별 호출 메시지를 수신하는 수신부; 내장 GNSS로 취득한 자선 위치가 경보 지리영역에 포함되는지 또는 목적지 식별자가 자선과 일치하는지 판별하는 판별부; 자선 대상 시 조타실 외부 갑판·기관실 스피커·경광등을 강제 구동하는 다중구역 경보부; 상기 스피커 구동회로의 전류 또는 부하 변화를 감지하여 경보의 실제 발현 여부를 검증하는 발현 검증부; 및 경보 발동 시각·참조식별자·지속시간·검증결과를 위변조 방지 저장소에 기록하는 발현 기록부;를 포함하고, 위험 판정 권한은 데이터 패킷을 발신한 외부 관제국에 한정되는 것을 특징으로 하는, 수신 전용 선박 안전 예방경보 장치.

> **신규성 집중**: 독립항 핵심 = "무송신 수신전용 + 다중구역 강제 + 폐루프 발현검증 + 위변조 로컬 발현기록 + 위험판정 발신측 한정"의 결합. 자동채널전환·음성중계(제8항)는 US2010 공개로 종속항 배치.

**【청구항 2】(종속 — 항적 반응 격상)** 경보 발동 후 기설정 시간(예:300초) 이내 GNSS 측정 속도가 기설정 임계(예:0.5knot) 초과 변화가 없으면 음량·점멸을 자동 격상.

**【청구항 3】(종속 — 폐루프 지각검증 결합)** 발현 검증 결과와 항적 변화 감지 결과를 결합해 "발현+반응" 지각검증 정보를 생성·기록.

**【청구항 4】(종속, 선택 — 음압센서 병용)** 발현 검증부가 갑판/기관실 음압을 감지하는 음향센서를 더 포함해 경보음이 기설정 음압 임계 이상 발현됐는지 추가 검증.

**【청구항 5】(종속 — 전원단절 증거봉인)** 주전원 단절 감지 즉시 슈퍼커패시터 잔존에너지로 최종시각·단절 이벤트코드 기록 후 봉인.

**【청구항 6】(종속 — 부인방지 로그)** 각 이벤트를 HSM 키로 서명해 append-only 해시체인으로 누적저장(위변조 검출 가능).

**【청구항 7】(종속 — 식별자 위변조 방지)** 인증정보·MMSI를 HSM 봉인, 무단 변경·이동장착 감지 시 동작 영구 잠금.

**【청구항 8】(종속 — 음성 중계, 신규성 이슈로 종속)** 후속 통화채널 정보로 음성 주파수 자동전환해 관제국 음성을 스피커로 실시간 중계. (※ US2010 공개 요소.)

**【청구항 9】(종속 — 환경/연동/발신자신뢰)** IP67·태양광·자력거치 / NMEA·JSON 로그 출력 인터페이스 / 공인 발신자 화이트리스트 중 하나 이상.

**【청구항 10】(방법 — 선택)** 수신 → GNSS 자선대상 판별 → 갑판·기관실 강제구동 → 구동회로 되먹임 발현검증 → 위변조 저장소 기록 단계.

**【청구항 11】(종속 — 정적 위험구역 자율감지, 취약점 보정판 — 상세는 16.7절)** 제1항에 있어서, 상기 판별부는 공적으로 발행된 고정 위험구역(해상풍력단지·군사구역·항로 등)의 좌표 데이터를 사전 저장하고 자선 위치와 대조하여 진입 여부를 판별하며, 진입 판별 시 외부 관제국이 발신한 경보 수신 시와 동일하게 상기 다중구역 경보부, 상기 발현 검증부 및 상기 발현 기록부가 구동되어, 국지적으로 트리거된 경보에도 외부발신 경보와 동일한 강제전파·검증·부인방지 기록 경로가 적용되는 것을 특징으로 하는 선박 안전 예방경보 장치. (※ 단순 "좌표 대조 후 경보"는 MFD 지오펜스 알람과 겹쳐 위험 — 파이프라인 재사용 결합으로 한정할 것, 16.3~16.5절 참조.)

> **작성 원칙**: 상용 부품명·수치는 독립항 금지, 종속항/실시예 예시로만.

**[전달]** ④갑판·기관실 다중구역 강제(부재 청자 도달) ⑤무조작·무발화 앰비언트.
**[검증·증명(전무)]** ⑥폐루프 발현검증(무센서: 앰프전류+항적) ⑦부인방지 로컬로그(HSM 해시체인) ⑧항적 무변화 기반 격상(≠타이머).
**[프레임 정밀화]** ⑨"이해 개선(개루프)"→"부재 청자 도달 보장+검증+증명(폐루프+증거)".
**[구현·전략]** ⑩자체 GNSS 단일모델 ⑪저비용 무센서(기존 앰프·GPS 재사용) ⑫정부(KR388608)와 방향 일치→협력 지렛대.

### 14.4 신규성 프레임 정밀화 (3장 보정)
3장의 "송신 vs 지각+증명"은, KR388608도 "인지 향상"을 목적으로 하므로 한 단계 더 좁힌다: **"곁의 청자 이해 개선(개루프) vs 부재 청자 도달 보장 + 물리 검증 + 부인방지 증명(폐루프+증거)".** "지각" 단독으로는 KR388608에 먹히므로 이 정밀 프레임을 사용한다.

### 14.5 KR388608 협력 지렛대 전략
KR388608은 정부(대한민국) 소유 → 침해소송 리스크 낮고 라이선스·활용 열림. 본 발명은 해수부·KOMSA 해양안전 정책과 방향 일치 → **경쟁 장벽이 아니라 채택·협력 지렛대**로 접근(로드맵 Step 3 연계).

## 15. V-PASS 대비 분석 및 FTO 후보 (별도 검토항 — 2026-07-07 추가)

> 본 절은 기존 선행기술 분석(2~6·13·14장)과 별개로, 어선 의무장비 V-PASS와의 관계만 독립적으로 정리한 것이다.

### 15.1 V-PASS 기능 요지 (원문 확인)
어선 **의무장비**(어선법), **해양경찰청 운영**, 통신거리 ~30km, **음성통신 없음**. 주기능은 **발신 위주** — 위치 발신(항적), 자동 출입항 신고, 조난/SOS 발신. **디스플레이형(삼영ENC SPA-900D)**은 추가로 지도·항적 관리, 다중 GNSS, **기상정보·문자메시지 수신·표시·알림**(7인치 LCD). 기본형은 발신 위주라 메시지 표시가 사실상 없음.

### 15.2 제1원리 대비 (겹치는 건 "수신·표시" 하나뿐)

| 근본 축 | V-PASS 디스플레이형(수신·표시) | 본 발명 |
| :-- | :-- | :-- |
| 장치 정체성 | 송신 장치(수신은 부가) | 순수 수신 장치 |
| 수신 데이터 | 기상·문자 텍스트 | VTS DSC 안전호출(+육성) |
| 출력 | 화면 텍스트+알림음 | 갑판·기관실 강제 음성·경광 |
| 청자 전제 | 화면 보는 사람(조타실) | 부재 승무원 |
| 작동 | 수동 표시(봐야 앎) | 무조작 강제 작동 |
| 검증·증명 | 없음 | 폐루프 검증 + 부인방지 로그 |

**판정**: 겹침은 "안전정보 수신·표시" 표면 하나. 근본은 "화면 표시(수동·청자 존재 전제) vs 부재 청자 강제 도달+검증+증명" → **KR388608과 동일 패턴**. **신규성 성립**(V-PASS는 화면 텍스트라 강제 다중구역+검증+증명 미개시), **진보성 방어**(V-PASS는 "화면 보는 사람" 전제 → 부재 승무원 문제 미해결, teaching away). 단 **"안전정보 수신"은 신규성으로 주장하지 않고 결합에 둔다**(V-PASS·KR388608·US2010·재난문자에 모두 존재).

### 15.3 실질 리스크 = 신규성 아닌 FTO(자유실시)
살아있는 V-PASS 메시지-수신 특허가 청구항을 "선박에서 안전 메시지를 수신해 알린다"로 **넓게** 잡았을 경우 내 "수신·경보" 요소가 침해에 걸릴 수 있음 → **KIPRIS 확인이 이 건의 핵심.** (신규성 문제가 아니라 침해 문제)

### 15.5 전략 — 경쟁 아닌 재활용·협력 (마션 doctrine)
V-PASS는 장벽이 아니라 **재활용 발판**: GPS·위치송신(=내 무송신 ACK 경로)·수신 인프라를 그대로 씀. 내 기기는 V-PASS가 없는 **"강제 작동+검증+증명" 층만** 얹음. 특히 노후·저가선의 **기본형 V-PASS엔 안전정보 전달 수단이 사실상 없어** 그 공백을 값싸게 메움 → **V-PASS 파생/부가 모듈**로 접근하면 원가↓·정부 보급망(4만여 척)↑. **삼영ENC=상장 제조사 → OEM·라이선스·협력 파트너**(KR388608 정부처럼 협력 지렛대).

## 16. 정적 위험구역 자율 진입감지 (부각점13 — 2026-07-08 추가, 2026-07-08 취약점 발견·보정)

> 본 절도 기존 분석과 별개로 독립 추가한다. 새 하드웨어가 아니라 **트리거 유형의 구분**이다.

### 16.1 두 가지 트리거 유형

| 유형 | 예 | 판정 주체 | 처리 방식 |
| :-- | :-- | :-- | :-- |
| 동적 위험 | 태풍·충돌위험·실시간 기상특보 | VTS 실시간 판단·호출 | 기존 설계(위험판정 발신측 한정 원칙, 3·5장) |
| **정적 위험구역** | 해상풍력단지·군사구역·항로·양식장 | **이미 공표된 고정 좌표**(법규·고시) | **기기에 사전 저장, 자율 판단** |

정적 구역은 "위험을 판단"하는 게 아니라 "**이미 정해진 경계선과 내 위치를 대조**"하는 것뿐이므로, "위험판정은 발신측 책임"이라는 본 발명의 핵심 원칙(부각점3)을 위배하지 않는다 — 경계선 자체를 정한 주체가 발신측(정부·풍력단지 운영사)이기 때문이다. VTS가 실시간으로 매번 호출을 보내지 않아도, 기기가 사전 로드된 좌표 DB로 자율 판단해 즉시 경보 가능.

### 16.2 가치 — VTS 업무 경감
VTS가 모든 어선을 실시간 감시하지 않아도, 기기가 스스로 고정구역 진입을 감지해 경보하므로 **VTS는 예외상황에만 개입**하면 된다. 국내 해상풍력단지 확대(신안·울산 등) 추세와 맞물려 실증력 있는 사용례다.

### 16.3 ⚠️ 취약점 발견 (2026-07-08) — 지오펜스 자체는 이미 표준기술

**계기**: 청구항11 초안("좌표 대조 후 경보 구동")을 그대로 변리사에게 넘겨도 되는지 자체 재검토한 결과, 실질적 위험을 발견했다.

**웹 검증 결과**: "지오펜스+경보"는 전자해도·MFD(차트플로터)에 **이미 수십 년째 표준 기능**이다. Garmin·Furuno·Raymarine 등 상용 장비에 **경계 경보(border alarm)·정박 경보(anchor alarm)·위험구역 알람(alarm zone)**이 내장되어 있고, 관련 미국특허도 다수 실재한다(예: [US 12,379,216 "Anchoring systems and methods for marine vessels"](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/12379216), [US 11,674,806](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/11674806)).

**함의**: 청구항11을 "좌표 대조 후 경보"로만 쓰면, 심사관이 특정 인용문헌 없이도 **주지관용기술**(통상의 기술자가 이미 아는 기술)이라며 진보성을 거절할 수 있다. 이는 본 발명이 지켜온 "신규성은 결합에만 둔다"는 원칙에서 이 조항만 예외적으로 벗어나 있던 것이다.

### 16.4 제1원리 분해 — 겹치는 축과 안 겹치는 축

**MFD 지오펜스 알람(기존 표준기술)의 근본 원리**: 트리거=로컬 GPS×**사용자가 임의로 그린 구역**(정박경보). 출력=**조타실 화면 표시+로컬 비프음뿐**. 청자 전제=**화면을 보는 사람이 그 자리에 있음**. 검증·기록=**없음**(화면 반짝이고 끝). 구역 출처=**선원 임의 지정**(공적 근거 없음).

| 축 | MFD 지오펜스 | 본 발명 | 판정 |
| :-- | :-- | :-- | :-- |
| A. 트리거 메커니즘(GPS×구역 대조) | 있음 | 있음 | **겹침 — 이 축만으로 청구 불가** |
| B. 출력 경로(다중구역 강제+검증+로그) | 없음(화면뿐) | 있음 | 안 겹침 |
| C. 청자 전제(부재 승무원) | 없음(사람 있음 전제) | 있음 | 안 겹침 |
| D. 구역 출처(공적 발행 vs 임의 지정) | 임의 | 공적 | 안 겹침(부수적) |

**결론**: A축(지오펜스 계산 자체)은 이미 공유지(public domain)라 독자적으로 청구하면 위험하다. B·C·D축은 안 겹친다.

### 16.5 우회로 — 두 개의 독립적 방어선

**우회로① 파이프라인 재사용 프레이밍(가장 강함)**: "지오펜스로 감지한다"가 아니라 "**감지 후 무엇이 일어나는가**"로 청구를 옮긴다. KR388608 대응 때(합성음성 자체가 아니라 "육성 중계"라는 결과로 청구) 쓴 것과 동일한 전략이다. 국지적 트리거라도 **외부발신 경보와 완전히 동일한** 다중구역 강제전파+발현검증+부인방지기록 파이프라인을 태운다는 점 — 이게 MFD 지오펜스가 절대 못 하는 부분이다(MFD는 화면·비프음에서 끝).

**우회로② 구역 출처의 공적 성격 명시(보조 방어선)**: MFD 지오펜스는 선원이 임의로 그린 구역(정박지 등)이다. 본 발명은 정부·공식기관이 발행한 고정 경계(해상풍력단지 고시, 군사구역, 항로)만 다룬다. 이는 신규성보다는 "위험판정 발신측 한정"이라는 본 발명 전체 철학과의 **정합성**을 강화한다 — "선원의 주관적 판단"이 아니라 "공적으로 이미 확정된 사실을 로컬에서 반영"이라는 프레임.

### 16.6 신규 부각점 13 (보정판)
**[전략·구현]** 13) **사전 등록된 정적 위험구역 자율 진입감지 — 단, 지오펜스 계산 자체가 아니라 "국지적 트리거를 외부발신 경보와 동일한 강제전파·검증·부인방지 파이프라인에 편입시킨다"는 결합이 신규성의 핵심.** 새 센서·통신 없이 좌표 DB만 펌웨어 추가(마션/보이저 원칙 부합), VTS 업무 경감 효과. (↔ MFD 지오펜스 알람: 화면·비프음뿐, 검증·기록 없음)

### 16.7 청구항 반영 (제8장 갱신 — 취약점 보정판)
**【청구항 11】(종속 — 정적 위험구역 자율감지, 보정판)** 제1항에 있어서, 상기 판별부는 공적으로 발행된 고정 위험구역(해상풍력단지·군사구역·항로 등)의 좌표 데이터를 사전 저장하고 자선 위치와 대조하여 진입 여부를 판별하며, 진입 판별 시 외부 관제국이 발신한 경보 수신 시와 **동일하게** 상기 다중구역 경보부, 상기 발현 검증부 및 상기 발현 기록부가 구동되어, **국지적으로 트리거된 경보에도 외부발신 경보와 동일한 강제전파·검증·부인방지 기록 경로가 적용**되는 것을 특징으로 하는 선박 안전 예방경보 장치.

**명세서 추가 문구**: "종래 전자해도·MFD의 지오펜스 알람은 사용자가 임의 지정한 구역에 대해 조타실 화면·비프음으로만 표시되며, 검증·부인방지 기록 기능이 없다(선행기술 US12,379,216 등 다수 MFD 정박·경계 경보 참조). 본 발명은 공적으로 발행된 고정구역을 대상으로, 국지적 트리거를 외부발신 경보와 동일한 강제전파·검증·증명 파이프라인에 편입시킨다는 점에서 구별된다."
