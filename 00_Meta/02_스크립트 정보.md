### 증상별 진단 순서

| 증상 | 먼저 확인 | 원인 | 조치 |
|---|---|---|---|
| 응답 엔진이 갑자기 바뀜 | 텔레그램 `⚠️ [자동 폴백]` 알림 | Circuit Breaker 발동 | 60초 대기 자동 복구. 즉시 필요 시 `/restart_bot` |
| 루프가 중간에 멈춤 | `/orchestrate mayor` 대시보드 | Mayor 예산/반복 초과 | 작업을 더 작게 나눠 재시도 |
| 답변에 ⚠️ 파일 경고 블록 | 경고된 파일명 실제 존재 확인 | LLM 환각 (파일명 날조) | 경고 내용대로 수동 확인 후 사용 |
| 오래된 대화 맥락이 사라짐 | `harness_memory.json` 첫 항목 확인 | 30턴 초과 → 자동 압축 | 정상. 최근 10턴은 그대로 보존됨 |
| LLM이 검색 결과를 지시로 따름 | 로그에 `[TOOL_OUTPUT_START` 존재 여부 | ToolResult 래핑 실패 | `modules/tool_result.py` 파일 존재 확인 |
| 컨텍스트(날씨/메모리/wiki) 누락 | `context_assembler.py` 각 try/except | assemble_context 내부 오류 | 각 블록 개별 확인 (날씨=BS4, 메모리=memory_refinement, wiki=wiki_manager) |
