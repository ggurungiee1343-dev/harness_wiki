## 📂 1. 설치 및 가동 중인 플러그인 상세

현재 보관소 시스템 환경(`.obsidian/community-plugins.json`) 분석 결과, 추천드린 핵심 연동 플러그인들이 모두 정상 설치되어 있습니다.

| 플러그인명 (ID) | 현재 상태 | 주요 역할 및 기능 | 시스템(하네스/헤르메스) 연동 및 활용 시너지 |
| :--- | :---: | :--- | :--- |
| **Advanced URI**<br>`obsidian-advanced-uri` | **설치 완료** | 외부 앱/스크립트에서 옵시디언 노트를 열거나 조작할 수 있는 고급 스키마 링크 제공 | 텔레그램 봇이 알림 메시지를 보낼 때 맥의 옵시디언 앱에서 해당 노트를 즉시 띄우는 단축 링크(`obsidian://advanced-uri?vault=...`)를 첨부하는 데 사용됩니다. |
| **Dataview**<br>`dataview` | **설치 완료** | 노트 내 메타데이터(YAML frontmatter)를 쿼리하여 동적 테이블, 리스트 생성 | `/ingest`로 수집된 자료 중 "최근 7일간 연구 문서 목록" 등을 특정 대시보드 노트에 자동으로 모아주고 모니터링하기 위해 사용됩니다. |
| **Smart Connections**<br>`smart-connections` | **설치 완료** | AI 기반 벡터 임베딩을 통해 작성 중인 노트와 관련 깊은 다른 노트를 실시간 추천 | 로컬 임베딩 모델 또는 Gemini API 키를 활용하여, 박사님이 문서를 작성할 때 과거의 유사 맥락 노트를 사이드바에 즉시 시각화해 줍니다. |
| **Local REST API**<br>`obsidian-local-rest-api` | **설치 완료** | 옵시디언 내부에 암호화된 로컬 HTTPS REST API 서버를 기동 | 봇의 `file_manager.py`가 디스크 파일 직접 쓰기 외에도, API를 통해 옵시디언 인덱스 파괴 없이 실시간으로 데이터를 밀어 넣고 검색할 수 있는 통로가 됩니다. |
| **Omnisearch**<br>`omnisearch` | **설치 완료** | 오타 보정 검색 및 문서 내 첨부된 이미지(OCR), PDF 문서 전체 텍스트 검색 지원 | 크롬 웹 클리퍼로 수집한 자료 중 이미지 및 PDF 파일이 섞여 있어도 키워드 하나로 관통하는 강력한 검색 환경을 제공합니다. |
| **Calendar**<br>`calendar` | **설치 완료** | 우측 사이드바에 달력 뷰를 띄워 날짜별 데일리 저널(Daily Notes)로 바로 이동 | `/dreaming` 시 자동 기록되는 일일 저널(Journal)들을 달력 뷰와 유기적으로 매핑하여 일자별 활동을 쉽게 탐색하도록 돕습니다. |

## ⚙️ 2. 하네스 자동화 시스템과의 연동 최적화 설정 가이드

### 1) 크롬 웹 클리퍼 첨부파일 경로 맞춤
박사님이 설치하신 **크롬 옵시디언 웹 클리퍼(Web Clipper)**가 이미지를 포함해 스크랩할 때, 첨부파일들이 `Clippings` 폴더 내부로 깔끔히 들어가도록 아래와 같이 설정을 맞춰주시면 `/ingest` 이관 시 경로 꼬임 오류를 예방할 수 있습니다.
*   **설정 경로**: `옵시디언 설정` ➔ `Files and links` ➔ `Default location for new attachments`
*   **변경값**: `In the folder specified below` 선택 후 하단 폴더명을 `Clippings`로 지정

### 2) Advanced URI를 통한 텔레그램 스마트 열기 기능
헤르메스 봇이 박사님께 `/ask`나 `/recent` 결과를 보고할 때, 아래와 같은 커스텀 링크를 메시지에 함께 포함하도록 추후 기능 고도화 시 활용됩니다.
*   **예시 스키마**: `obsidian://advanced-uri?vault=Mjobsidian&filepath=00_Meta/hot.md`
*   이 링크를 텔레그램에서 클릭(또는 맥 터미널에서 `open` 실행)하면 맥에서 옵시디언 앱이 포커싱되며 `hot.md` 파일이 즉시 열립니다.
