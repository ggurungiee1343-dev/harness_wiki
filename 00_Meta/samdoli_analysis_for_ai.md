## 1. PDF5번 원본 내용 — "주식농사와 단타의 결합, 농사단타 기법"

### 1-1. 핵심 개념

```
농사와 단타의 동시 공략이 가능한 유일한 타이밍:
"급등 후 하락한 종목이 다시 강하게 반등할 때"
= 추세가 전환되는 타이밍

기법적으로:
  추돌이가 나옴과 동시에
  ① 반등선 아래 있던 종목이 반등선을 돌파하거나
  ② 노란선 아래 있던 종목이 반등선을 돌파하거나
  ③ 45일선 아래 있던 종목이 반등선을 돌파하는 경우

→ 이것이 "삼돌이 농사 검색기"
```

### 1-2. 실제 HTS 조건식 vs 기존 추정치 비교

| 일간 시총 필터 | 300억~5조 (추정) | **시총 상위 1,000종목** | ✅ 이미지 확정 |

### 1-3. 5분봉 차트 세팅 (PDF5번 p.6~10 원문)

```
1. 이동평균선 (지수이평, (고+저+종)/3)
   EMA5   = 25분선
   EMA20  = 100분선
   EMA390 = 5일선

2. 거래량가중이평선 (VWMA)
   노란선 (1일): n=78
   하늘선 (5일): n=390
   수식: A=(h+l+c)/3; B=A*v; X=Sum(B,n); Y=Sum(v,n); Z=X/Y

3. 분봉반등선 (DD)
   A = if(PreDayClose()>DayLow(), DayLow(), PreDayClose())
   B = DayHigh()
   DD = 0.5*(A+B)

4. 매수금지선 (분홍선)
   VWMA78 × 1.03

5. 5일 신고가 신호 ◆
   highest(c,390) <= h AND c(1) < c

6. 50억봉 신호
   c(1)*1.01 < h AND 거래대금 >= 5000 (G=5000, 백만원)

7. 매수신호 (눌림목)
   BB[3.5,33] + EMA 정배열 복합 수식

8. OBV
   기간: 78 (5분봉 Signal=78)
```

### 1-4. 실전 매매 흐름

```
Step1. 삼돌이 농사 검색기 → 아무리 많아도 20개 미만
Step2. 차트에서 추돌이 여부 확인 (일봉)
       → 반등선 위에 있는 종목만 공략
Step3. 5분봉 차트로 매수타점
       → 50억봉 신호(◆) 이후 눌림목에서 매수
       → 조건: 분봉 반등선 위 + 분홍선 아래 + OBV 주황선 > 검은선
       → 세번째 매수신호에서 매수
Step4. 손절: 노란선 + 하늘선 + 5분봉20선 모두 이탈
```

## 4. PDF5번 내용 vs 실제 HTS 차이 분석

```

4. 30분봉 OBV Signal 이중 구조: 65 or 195
```
