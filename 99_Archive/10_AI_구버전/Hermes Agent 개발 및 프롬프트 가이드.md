**## 작업 2: Agent의 patch 명령 전에 `git diff` 승인 단계 추가**

  

**### 왜 이 작업이 필요한가?**

**- 현재 Hermes Agent는 파일을 곧바로 수정(`patch/write`)합니다.**

**- #017 사고처럼 의도치 않은 부작용이 생겨도 **되돌리기 어렵습니다**.**

**- `git diff`를 먼저 보여주고 **MJ님의** ✅ **승인을 받은 뒤에만 적용**하는 안전장치를 추가하면, 이런 실수를 90% 막을 수 있습니다.**

  

**### 에이전트에게 시킬 프롬프트 예시**

  

**```**

**[작업 요청: 파일 수정 전 git diff 승인 플로우 추가]**

  

**너는 현재 hermes1_patch 명령어로 파일을 직접 수정하고 있어.** 

**이걸 아래와 같은 2단계 프로세스로 바꾸는 코드를 작성해줘.**

  

**<요구사항>**

**1. 어떤 파일을 수정해야 할 때, 너는 먼저 `git diff`를 생성해서 나에게 보여줘.**

   **- 방법: `git diff HEAD -- [파일경로]` 명령어 실행 결과를 텍스트로 캡처.**

   **- 만약 새 파일을 만드는 경우: `diff` 대신 추가될 파일의 전체 내용을 보여줘.**

**2. diff를 출력한 후, "이 변경사항을 적용할까요? (**✅**: 승인 /** 🚫**: 거절)" 라고 묻는 메시지를 출력.**

  

**3. 내가** ✅ **이모지로 응답할 때만 실제 파일 수정(patch/write)을 진행.**

  

**4. 내가** 🚫 **이모지로 응답하면, "변경이 취소되었습니다. 어떤 부분을 수정할까요?" 라고 묻고 대기.**

  

**<구현 방법>**

**- `hermes1_patch`의 래퍼 함수 `hermes1_patch_with_review()`를 새로 만들어줘.**

**- 기존 patch 로직은 그대로 두고, 함수 앞부분에 diff 생성 및 사용자 확인 단계를 추가.**

**- diff 생성은 `subprocess.run(['git', 'diff', 'HEAD', '--', filepath])` 로 실행.**

  

**<파일 위치>**

**- 수정할 파일: /Users/mj/hermes/modules/patch_manager.py**

  **(만약 파일이 없다면 새로 생성해도 됨)**

  

**<작업 후 테스트>**

**- patch_manager.py를 작성한 뒤, "이 diff 승인 플로우가 작동하는지 시뮬레이션한 예시를 보여줘"**

**- 예: test.txt 라는 임시 파일을 만들어서, 그 파일에 대해 patch_with_review()를 호출했을 때**

  **어떤 식으로 diff가 보여지고 사용자 확인을 기다리는지 보여줘.**

**```**

  

**### 예상되는 에이전트의 작업 흐름**

**1. `patch_manager.py` 파일을 열거나 새로 생성**

**2. `hermes1_patch_with_review()` 함수 작성**

**3. 내부 로직:**

   **```python**

   **import subprocess**

   **def hermes1_patch_with_review(filepath, new_content):**

       **# 1단계: diff 생성**

       **diff_result = subprocess.run(**

           **['git', 'diff', 'HEAD', '--', filepath],**

           **capture_output=True, text=True**

       **)**

       **diff_text = diff_result.stdout**

       **# 2단계: diff 출력**

       **print(f"--- 변경 예정: {filepath} ---")**

       **print(diff_text if diff_text else "[새 파일] 전체 내용:\n" + new_content)**

       **# 3단계: 사용자 확인**

       **response = input("이 변경사항을 적용할까요? (**✅**: 승인 /** 🚫**: 거절): ")**

       **if '**✅**' in response:**

           **# 실제 파일 수정**

           **with open(filepath, 'w') as f:**

               **f.write(new_content)**

           **print("변경 적용 완료")**

       **else:**

           **print("변경이 취소되었습니다. 어떤 부분을 수정할까요?")**

   **```**
