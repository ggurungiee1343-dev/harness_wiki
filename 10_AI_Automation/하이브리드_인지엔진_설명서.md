# 🧠 하이브리드 인지 엔진 (Cognitive Engine) 통합 설명서

## 1. 개요 및 목적
최근 `Llama 3.1 8B Instruct` 모델로 메인 엔진이 교체되면서 응답 속도와 자원 효율은 비약적으로 상승했습니다. 하지만 대형 모델(70B)에 비해 긴 컨텍스트를 잊어버리거나 뉘앙스 파악에 약한 단점이 존재합니다. 

이를 극복하기 위해 하네스 시스템 내부에 **인지 엔진(Cognitive Engine)**을 도입하여, **작은 모델의 단점을 파이썬 스크립트와 외부 대형 API(NVIDIA 70B)로 보완하는 하이브리드 아키텍처**를 완성했습니다.

## 2. 새롭게 추가된 핵심 기능

### 🧩 2.1. Map-Reduce 분할 요약 (컨텍스트 누락 방지)
- **문제점**: 8B 모델에 A4 10장 분량의 긴 코드를 주면, 앞부분의 세부 사항을 잊어버립니다.
- **해결책**: 스크립트가 긴 문서를 N개의 파트로 자동으로 자릅니다(Map). 8B 모델이 각 파트를 개별적으로 세밀하게 요약한 뒤, 마지막에 그 요약본들을 하나로 합칩니다(Reduce).
- **사용법**: 텔레그램 하네스 봇에서 `@분할요약 [파일경로]` 입력
  *예시: `@분할요약 /Users/bluesea/Applications/Mjauto/Scripts/harness_v2.py`*

### 🔄 2.2. 자가 치유 루프 (Self-Correction)
- **문제점**: 8B 모델은 코딩할 때 문법 에러나 띄어쓰기 실수를 종종 합니다.
- **해결책**: 에이전트가 `[RUN_CMD:]` 태그를 사용해 파이썬이나 쉘 스크립트를 자율 실행했을 때, **오류(Error/Exception)가 발생하면 봇이 당황하지 않고 스스로 에러 로그를 읽고 다시 코드를 고쳐서 실행**합니다. (1회 재시도 보장)

### 📚 2.3. 용어집 동적 주입 (Glossary Injection)
- **문제점**: 법률이나 공학, 코딩 등 특정 도메인의 대화에서 뉘앙스를 놓칠 수 있습니다.
- **해결책**: 질의에 특정 키워드(특허, 소송, 디버깅 등)가 포함되어 있으면, 봇이 사용자 모르게 시스템 프롬프트에 "단호한 법률 용어를 쓸 것", "주석을 꼼꼼히 달 것" 등의 제약사항을 실시간으로 끼워 넣어 뉘앙스를 대형 모델 수준으로 보정합니다.

### 🔀 2.4. 스마트 라우팅 (API 토스)
- **문제점**: 8B 모델이 감당하기 힘든 복잡도 높은 질문을 할 때가 있습니다.
- **해결책**: 질문 텍스트가 엄청나게 길거나, "정교한 스크립트" 등의 키워드가 있으면 하네스가 자체 판단하여 로컬 8B를 쓰지 않고, 백그라운드에 세팅된 **NVIDIA 70B 엔진으로 몰래 우회(Toss)**하여 답변을 가져옵니다.

## 3. 모드 전환 및 봇 운영 전략 가이드

박사님께서 NVIDIA 무료 API 3종을 준비해 주셨습니다. (현재 `.env`에 `Llama-3.1-70B` 키가 등록 완료되었습니다.)

**Q. 봇 1개로 모드를 바꿀까요, 텔레그램 봇 2개를 쓸까요?**
> **A. "하네스 봇(1개)을 주력으로 쓰되, 안티그래비티 봇은 백업(Failover)용으로 유지하는 것"을 강력히 추천합니다.**

### 💡 하네스 봇 (추천 메인 비서)
방금 개발한 **하이브리드 인지 엔진**이 하네스(`harness_v2.py`)에 모두 탑재되어 있습니다. 즉, 하네스 채팅창 하나에서 대화의 문맥(Context)을 유지하며 두 모델을 자유자재로 넘나들 수 있습니다.
- **평소 (로컬 8B 모드)**: 즉각적인 답변, 빠른 파일 저장, 텔레그램 딜레이 없음.
- **모드 전환 방법 (NVIDIA 70B 모드)**: 
  - 질문 앞에 `@심층` 태그를 붙이시면 됩니다.
  - *예시: `@심층 이 파이썬 스크립트에서 보안 취약점을 완벽하게 분석해 줘.`*
  - 이렇게 하면 하네스가 로컬 8B 대신 즉각 NVIDIA 70B 엔진을 호출하여 답변합니다.

### 🛡️ 안티그래비티 봇 (백업용 텔레그램 봇)
안티그래비티(`antigravity_bot_v2.py`)는 로컬 자원을 전혀 쓰지 않고 오직 NVIDIA API만 바라보도록 설계되어 있습니다. 
- 맥 스튜디오에 과부하가 걸려 Ollama 서버가 죽었거나 외부에서 하네스가 먹통이 되었을 때, **최후의 비상 통신망**처럼 사용하시면 됩니다.
