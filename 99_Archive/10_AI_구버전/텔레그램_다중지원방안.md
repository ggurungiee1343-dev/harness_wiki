# 텔레그램 다중 지원 방안

> Harness Gateway를 통해 가족 3명을 추가하여 총 4명이 각각 독립적으로 Harness와 소통할 수 있도록 하는 설정 가이드.

---

## 목표

| 항목 | 내용 |
|------|------|
| **구성** | MJ님 + 가족 3명 = 총 4명 |
| **접속 방식** |同一 Telegram Bot (각자 DM으로 연결) |
| **세션 격리** | Chat ID 기반으로 자동 분리 |
| **프라이버시** | 각 사용자는 다른 사람의 대화를 볼 수 없음 |
| **공유 자원** | 위키(Wiki)는 모두 접근 가능 |

## 현재 Harness Gateway 상태

```yaml
# ~/.hermes/profiles/remote/config.yaml
model: minimaxai/minimax-m2.7
telegram_enabled: true
gateway_allow_all_users: true          # ⚠️ 전체 허용 상태
telegram_allowed_users:
  - 5365732604                         # MJ님만 허용
```

## 세션 격리 작동 방식

```
Harness Gateway ── Telegram Bot
                  │
                  ├── Chat ID 5365732604 (MJ님) → 세션 A, 메모리 A
                  ├── Chat ID 1111111111 (가족A) → 세션 B, 메모리 B
                  ├── Chat ID 2222222222 (가족B) → 세션 C, 메모리 C
                  └── Chat ID 3333333333 (가족C) → 세션 D, 메모리 D
```

| 구분 | 동작 |
|------|------|
| **세션** | Chat ID마다 자동 생성·유지 |
| **기억** | Chat ID별 memory 자동 분리 (`~/.hermes/memories/{chat_id}/`) |
| **대화** | 본인 대화만可见 |
| **위키** | `Mjobsidian/wiki/`는 모두 읽기/쓰기 가능 |

## 설정 절차

### 1단계: 가족의 Telegram Chat ID 수집

가족이 Telegram에서 다음 방법 중 하나로 Chat ID를 확인합니다:

**방법 A: Bot 사용**
1. Telegram에서 `@userinfobot` 검색
2. 메시지 보내기
3. Bot이 `Your user ID: 123456789` 형태로 응답

**방법 B: @getidsbot 사용**
1. Telegram에서 `@getidsbot` 검색
2. 메시지 보내기
3. 상세 정보 확인

### 2단계: Config 업데이트

```yaml
# ~/.hermes/profiles/remote/config.yaml

# 변경 전
gateway_allow_all_users: true
telegram_allowed_users:
  - 5365732604

# 변경 후
gateway_allow_all_users: false          # whitelist 모드로 변경
telegram_allowed_users:
  - 5365732604                          # MJ님
  - 1111111111                          # 가족A (확인 후 교체)
  - 2222222222                          # 가족B (확인 후 교체)
  - 3333333333                          # 가족C (확인 후 교체)
```

### 3단계: Gateway 재시작

```bash
# LaunchAgent 재시작
launchctl unload ~/Library/LaunchAgents/com.hermes.gateway.remote.plist
launchctl load ~/Library/LaunchAgents/com.hermes.gateway.remote.plist

# 또는 gateway.pid 삭제 후 재시작
rm ~/.hermes/profiles/remote/gateway.pid
hermes gateway run --profile remote
```

## 개별 저장소 구조

설정 후 Harness는 Chat ID 기반으로 자동 분리됩니다:

```
~/.hermes/
├── memories/
│   ├── 5365732604/                    # MJ님 메모리
│   ├── 1111111111/                     # 가족A 메모리
│   ├── 2222222222/                     # 가족B 메모리
│   └── 3333333333/                     # 가족C 메모리
├── sessions/
│   ├── session_..._5365732604.json     # MJ님 세션
│   ├── session_..._1111111111.json     # 가족A 세션
│   └── ...
└── profiles/
    └── remote/config.yaml              # 공통 설정
```

##注意事项

1. **Chat ID 보안**: Chat ID는 telegram 내부 식별자이므로 외부에 공개하지 않습니다.
2. **gateway_allow_all_users: false**: whitelist 모드로 설정해야 다른 사용자가 접근할 수 없습니다.
3. **세션 분리**: Harness가 Chat ID를 자동으로 인식하여 각 사용자의 대화를 분리합니다.
4. **메모리 분리**: memory 시스템도 Chat ID별로 격리되어 서로의 기억을 볼 수 없습니다.
