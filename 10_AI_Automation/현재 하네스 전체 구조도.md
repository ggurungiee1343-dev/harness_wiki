## 📡 데이터 흐름 전체 지도

```
[사용자 텔레그램 명령어]
        ↓
[hermes_local.py → handlers/*.py]
        ↓ 에러 발생 시
[weakness_miner.record_failure()]
        ↓ 3회 반복
[텔레그램 알림 → 사람 확인]
        ↓ 수정 전
[proposal_validator.pre_check()]  ← weakness.db 조회
        ↓ 수정 후
[proposal_validator.record_result()]
        ↓ 승인
[코드 적용 + git commit]
        ↓
[다음 세션 SessionStart Hook]
[05_시스템 상태.md 변경 내용 자동 주입]
```

## 📈 데이터 축적 장기 가치

### WeaknessMiner (`~/.hermes/runtime/weakness.db`)

| 시점 | 예상 데이터 | 가능해지는 것 |
|---|---|---|
| **현재** | 0건 | 수집 시작 |
| **1개월** | ~50건 | 취약 핸들러 육안 식별 |
| **3개월** | ~150건 | 패턴 클러스터링 + 분기 리뷰 |
| **6개월** | ~300건 | CLAUDE.md 자동 개선 제안 |

**핵심 가치**: "에러가 나면 고친다" → "이 패턴이 반복되니 구조를 바꿔야 한다"

### Wiki Git 성장

| 시점 | 커밋 수 | 활용 |
|---|---|---|
| 현재 | 6 | 기본 복구 가능 |
