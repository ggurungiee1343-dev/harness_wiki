한국의 세무·세법 분야에서 가장 활발하게 쓰이고 추천할 만한 오픈소스 MCP는 **korean-law-mcp** (국가법령정보 MCP)입니다.
대한민국 법제처의 공인 API를 연결해 주며, 최근 업데이트를 통해 **국세청 판례와 조세심판, 관세해석 등 세법 전반의 조문과 최신 판례**까지 AI가 완벽하게 인용 검증(LLM 환각 방지)할 수 있도록 지원합니다.
Claude Desktop(PC용 클로드 앱)에 이 MCP를 연동하고 다운로드받는 방법을 단계별로 쉽게 안내해 드리겠습니다.
## 1단계: 국가법령정보 Open API 인증키 발급 (무료, 1분)
법제처의 실시간 법령 데이터를 가져오기 위해 공인 인증키(무료)가 필요합니다.
 1. **국가법령정보센터 Open API** 사이트에 접속해 회원가입 및 로그인을 합니다.
 2. 메뉴에서 **[공동활용 서비스] > [Open API 신청]**을 클릭합니다.
 3. 간단한 활용 목적(예: "AI 개인 비서 연동 테스트")을 입력하고 신청하면 **즉시 승인**되어 인증키(예: abc123XYZ...)가 발급됩니다. 이 키를 따로 복사해 둡니다.
## 2단계: 필수 프로그램 설치 (개발 환경 준비)
MCP 서버를 내 컴퓨터에서 구동하기 위해 Python과 Git이 필요합니다. (이미 설치되어 있다면 건너뛰셔도 됩니다.)
 * **Python 설치:** Python 공식 홈페이지에서 최신 버전을 다운로드하여 설치합니다. *(Windows 설치 시 반드시 **"Add Python to PATH"** 체크박스를 체크하세요!)*
 * **Git 설치:** Git 홈페이지에서 설치합니다.
## 3단계: MCP 소스코드 다운로드 및 설정
컴퓨터의 터미널(Mac) 또는 명령 프롬프트/PowerShell(Windows)을 열고 아래 명령어를 순서대로 입력합니다.
```bash
# 1. 원하는 폴더로 이동 후 오픈소스 저장소 복제 (다운로드)
git clone https://github.com/chrisryugj/korean-law-mcp.git
cd korean-law-mcp

# 2. 필요한 파이썬 패키지(의존성) 설치
pip install -r requirements.txt

# 3. 환경 설정 파일 만들기
cp env.law.example .env

```
이제 다운로드한 폴더 안에 생성된 .env 파일을 메모장 등으로 열고, 아까 1단계에서 발급받은 법제처 API 키를 입력하고 저장합니다.
```ini
LAW_API_KEY=발급받은_인증키를_여기에_붙여넣으세요

```
## 4단계: Claude Desktop에 MCP 연결하기
Claude Desktop 앱이 내 컴퓨터에 깔려 있는 상태여야 합니다. 설정 파일을 열어 MCP 서버 정보를 등록해 줍니다.
### 설정 파일 위치로 이동
 * **Windows:** 키보드의 Win + R을 누르고 %APPDATA%\Claude\를 입력 후 엔터 -> claude_desktop_config.json 파일을 메모장으로 엽니다.
 * **Mac:** Finder에서 ~/Library/Application Support/Claude/ 경로로 이동하여 claude_desktop_config.json 파일을 엽니다.
### 설정 내용 추가
파일 안에 아무것도 없다면 아래 내용을 통째로 붙여넣고, 이미 내용이 있다면 "mcpServers": { ... } 괄호 안에 추가합니다.
```json
{
  "mcpServers": {
    "korean-law": {
      "command": "python",
      "args": ["-m", "src.law_main"],
      "cwd": "C:/설치한경로/korean-law-mcp",
      "env": {
        "LAW_API_KEY": "발급받은_인증키"
      }
    }
  }
}

```
> ⚠️ **주의:** "cwd" 부분에는 3단계에서 korean-law-mcp를 다운로드받은 실제 컴퓨터 폴더 경로를 정확하게 적어주어야 합니다. (예: C:/Users/Username/korean-law-mcp)
> 
## 5단계: Claude 실행 후 테스트하기
모든 설정이 끝났다면 **Claude Desktop 앱을 완전히 종료했다가 다시 실행**합니다.
오른쪽 하단 채팅창 주변에 **플러그인 모양(또는 콘센트 모양)의 MCP 아이콘**이 활성화된 것을 볼 수 있습니다. 이제 일반 대화를 하듯 세법을 물어보시면 됩니다.
> **대화 예시:**
>  * *"소득세법 제55조에 따른 세율 구조가 어떻게 돼?"*
>  * *"종합부동산세법에서 1세대 1주택자 고령자 세액공제율을 확인해 줘."*
>  * *"최근 바뀐 상속세 관련 양도소득세 조세심판원 판례가 있으면 조회해 줄래?"*
> 
이제 Claude가 임의로 지셔널 정보를 지어내지 않고, 법제처 API를 통해 실시간으로 조문을 긁어와 정확한 법적 근거에 기반한 세무 안내를 제공하게 됩니다!
