### `modules/code_graph.py` 신규 (2026-07-03) — 경량 코드베이스 지식그래프

외부 MCP 도구(`codebase-memory-mcp`) 대안으로 자체 구현. Python 표준 라이브러리 `ast`+`sqlite3`만 사용(신규 의존성 0개), MCP 서버 아닌 CLI 스크립트.

| 함수 | 역할 |
|---|---|
| `build_index()` | `Scripts/` 전체 AST 파싱 → `Scripts/.hermes_code_graph.db`에 함수/클래스/import/호출관계 저장(전체 재빌드 방식, 증분 아님) |
| `find_callers(func_name)` | 이 함수를 호출하는 곳 전부(파일:라인) |
| `find_importers(module_substr)` | 이 모듈을 import하는 파일 전부 |
| `get_file_summary(rel_path)` | 파일 내 함수/클래스/import 목록 |
| `_CodeVisitor(ast.NodeVisitor)` | 함수/클래스 스택 추적하며 호출관계 추출 — 중첩 함수/메서드도 qualified name으로 정확히 기록 |

**CLI**: `python3 modules/code_graph.py --rebuild` / `--callers 함수명` / `--importers 모듈명` / `--file 경로`

**검증**: 168개 파일 0.25초 인덱싱, 실패 0. `find_importers("deriver_layer")` 결과가 수동 grep 결과와 정확히 일치 확인.

**에러 진단 포인트**: 코드 변경 후 쿼리 결과가 안 맞으면 `--rebuild` 먼저 실행 필수(자동 갱신 안 됨). DB 손상 의심 시 `rm Scripts/.hermes_code_graph.db` 후 재빌드.
