# 🛡️ 에이전트 가드레일 (Harness Agent Guardrails)

본 가드레일은 환각(Hallucination)의 원천 차단 및 지식 자산의 누적 무결성을 보장하기 위한 강제 지침입니다. 모든 에이전트는 답변 생성 전 다음 **3대 관제 원칙 기반의 자가 검증 루프**를 준수해야 합니다.

---

## 🚦 3대 관제 원칙 자가 검증 루프 (3 Core Checklists)

### 1. Grounding 검증 (Rule 1 대응)
- [ ] 내가 제시하려는 파일 목록이나 내용은 실제 실행한 `[LIST: 경로]` 또는 `[READ]` 결과 데이터와 100% 일치하는가?
- [ ] 단 한 글자의 오타나 상상의 존재가 없는가?
- [ ] 100자 이하의 단독 파일/목록 조회가 아닐 경우, LLM으로 강제 바이패스 처리가 이루어졌는가?

### 2. 무결성 및 구조 검증 (Rule 2 대응)
- [ ] 사용자 계정명 `bluesea` 및 절대 경로 `/Users/bluesea/Applications/...` 기준을 엄격히 준수하고 있는가?
- [ ] 주요 아키텍처나 기능에 변화가 생겼을 때 `스크립트 정보.md`, `hot.md` 등 위키 파일에 관련 변경 사항을 모두 반영하였는가?
- [ ] 오류가 났을 때 자율적인 `[ROLLBACK]` 대책이 마련되어 있는가?

### 3. 지식 보존 검증 (Rule 3 대응)
- [ ] 박사님이 기존에 기재해 둔 상세 작동 원리나 지식 노트를 임의로 지우거나 줄여서 덮어쓰지 않았는가?
- [ ] 추가/수정된 문장 하단에 정밀한 타임스탬프(`YYYY-MM-DD HH:MM`)가 포함되었는가?

---
**🚨 Critical Rule:**
위 3대 검증 결과 중 단 하나라도 만족하지 못할 경우 해당 답변은 즉시 폐기하고 재작성해야 합니다. 위반 시 시스템 장애와 동일하게 간주됩니다.
