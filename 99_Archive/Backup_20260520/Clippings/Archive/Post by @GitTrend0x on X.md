Hermes 또 집단 진화했어!

경량 웹 UI, 네이티브 워크스페이스, 실시간 대시보드+위키, Meta 반성 스킬 팩, Awesome 커뮤니티 성경…… 전넷 프로그래머들이 Hermes를 다음 세대 Agent 이동 지휘대 + 워크스페이스 + 영혼 모니터링 캡슐 + 자기 반성 마스터 + 네비게이션 맵으로 만들어 버렸어:

1️⃣ hermes-webui（https://github.com/nesquena/hermes-webui…）

경량 다크 웹 UI, 브라우저/폰 완전 채팅 + 실시간 스트림 + Mermaid + 음성.

"폰으로 Agent 지휘" 천장 확정!

2️⃣ hermes-workspace（https://github.com/outsourc-e/hermes-workspace…）

네이티브 웹 워크스페이스: 채팅+터미널+메모리+스킬+서브 Agent 일체형, 한 줄 curl로 끝.

Agent 지휘 센터 오픈😂

3️⃣ hermes-dashboard（https://github.com/Kori-x/hermes-dashboard…）

실시간 모니터링 + 자동 위키, skills/plugins/memory/soul 원클릭 검색.

"드디어 Agent 영혼을 이해할 수 있게 됐어!"

4️⃣ super-hermes（https://github.com/Cranot/super-hermes…）

Meta 사고 스킬 팩: 자기 prompt 작성 + 보고서 "뭐 찾았는지+뭐 놓쳤는지".

Agent가 반성 블라인드 스팟 배우기, 진짜 meta!

5️⃣ awesome-hermes-agent（https://github.com/0xNyk/awesome-hermes-agent…）

1.7k+ 스타 커뮤니티 성경, skills/tools/forks 전부 수록.

Hermes 플레이어의 "네비게이션 맵" 확정!
