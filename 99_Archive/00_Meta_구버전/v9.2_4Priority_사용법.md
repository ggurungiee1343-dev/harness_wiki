## Priority 1: Tag 한글 보안 ← `_approval.py` 수정

**문제**: `/tag 테스트 좀` 같은 한글 쿼리가 셸로 전달되어 깨짐
**해결**: `shlex.quote()` + `VALID_ACTIONS` 화이트리스트 3중 차단

**사용법**: 변화 없음. 기존처럼 `/tag pending | approve <id> | reject <id>` 쓰면 됨.
- 한글/의미 없는 명령어는 자동으로 **일반 QA fallback**
- 더 이상 태그 버그 안 남

**핵심 효과**: ❌ 한글 명령어 셸 깨짐 버그 완전 제거 + 태그/일반질의 명확 분리

## Priority 2: Exec/File 3중 보안 필터 ← `core_reducer.py` 수정

**문제**: `/exec`에 위험한 명령어나 한글 실행 가능, `/file`로 경로 탈출 가능
**해결**: `_execute_exec` + `_execute_file` 각각 3단계 방어

**Exec 3중 필터**:
1. 블록리스트: `rm -rf`, `mkfs`, `dd`, `fork` 폭탄 → 차단
2. 한글 검사: 한글 포함 → 일반 질의로 전환 (실행 안 됨)
3. 30초 타임아웃: 무한 루프 방지

**File 3중 필터**:
1. 한글/특수문자 포함 경로 → 실행 차단
2. `realpath()` 정규화 후 `/Users/bluesea/Applications/` 경로만 허용 (../../etc 탈출 차단)
3. 100MB 파일 크기 제한

**핵심 효과**: ❌ `rm -rf /` 방지 · ❌ `../../etc/` 경로 탈출 차단 · ❌ 한글 깨짐 방지 · ✔️ 0.5ms 검증

## Priority 3: 3개 신규 엔진 ← `sia_engine.py` + `monitoring_engine.py` + `load_balancer.py`

이 Priority만 **진짜 신규 파일 3개**가 생겼다.

### ① SelfImprovingAgent (SIA)
- `~/.hermes/runtime/sia_feedback.db`에 사용자 👍/👎 피드백 축적
- `analyze_trends()` → 액션별 평점 추세 확인
- `get_low_performers(3.0)` → 평점 3.0 이하 액션 자동 감지
- `suggest_improvements("ask")` → LLM이 개선 제안 생성

**언제 유용**: "요즘 exec이 자꾸 실패하는데" → SIA가 데이터로 증명

### ② MonitoringEngine
- `~/.hermes/runtime/metrics.db`에 메트릭 기록
- `alert_if_degradation()` → 10%↑ 에러율 / 3초↑ 응답시간 / 80%↓ 성공률 자동 경고
- `get_performance_trend()` → 시간대별 성능 차트 (차트 툴 연동 가능)

**언제 유용**: 봇이 갑자기 느려졌을 때 "어디가 막혔는지" 바로 파악

### ③ ModelLoadBalancer
- 3개 모델(Gemma4/DeepSeek/NVIDIA)의 **응답시간 + 성공률** 기반 자동 선택
- 가중치 공식: `1.0 / (응답시간 × (1-성공률 + 0.01))`
- 확률적 선택 → 탐험(exploration) 보장
- `hybrid_router.py` 모든 API 호출에 자동 통합

**언제 유용**: DeepSeek이 갑자기 느려지면 자동으로 NIM/Gemma로 전환. 별도 설정 불필요.

## Priority 4: ArchitecturalJudgmentGate ← `core_reducer.py` 클래스

**문제**: `/status`, `/ping` 같은 간단한 명령어도 LLM 태워서 1~3초 + 토큰 소모
**해결**: 5개 결정론적 숏컷을 클래스로 분리, LLM 0회 호출

**지원 명령어**:
| 명령어 | 효과 |
|--------|------|
| `/status` | PAUSED/RUNNING 상태 확인 |
| `/pause` | 모든 처리 차단 |
| `/resume` | 재개 |
| `/ping` 또는 `ping` | health check |

접두사 매칭이라 `ping local`, `ping all` 다 통함.

**핵심 효과**: ⏱️ 0.5ms 응답 · 💰 토큰 0원 · 📊 MonitoringEngine과 연동되어 추적 가능
