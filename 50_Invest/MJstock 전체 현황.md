### 3개 파일에서 발견한 누락/불일치 사항

**사용설명서에 빠진 것들:**

**1. 검색식 vs 시그널 관계 — 가장 중요한 개념인데 설명서에 약하게만 서술** 퀀트 파일에 명확히 정의되어 있음:

```
검색식 = 후보 종목 선발전 (1차 필터)
시그널★ = 실전 진입 출발선 (2차 타점)
진입 가능 = 검색식 통과 AND ★ 발생 AND 체크리스트 합격
```

점수 높아도 ★ 없으면 진입 불가. 이게 핵심인데 설명서에서 약하게 다룸.

**2. 신호 유효기간(Signal Decay) — 설명서에 없음**

```
0일(오늘):  🟢 최신 — 즉시 진입 가능
1~3일:      🟡 유효 — 이격률 15% 이내면 진입
4~7일:      🟠 주의 — E4 과열선 확인 필수
8일 이상:   🔴 만료 — 다음 신호 대기
```

**3. 과거 ★가 차트에 안 보이는 이유 — 설명서에 없음**

```
★는 스캔 실행 시점에만 계산됨
나중에 차트 열면 오늘 데이터로 재계산 → 과거 봉에 소급 불가
과거 이력은 tracker/signal_log.csv에서만 확인
→ 매일 스캔해야 이력이 쌓임
```

**4. 자석구간 상세 규칙 — 설명서에 "자석구간 안 매수 금지"만 있고 세부 기준 없음** 시그널 파일에서 확인한 실제 규칙:

```
자석구간 안 + ★ + C2 위   → ✅ 진입 가능 (A급)
자석구간 안 + ★ + C2 아래 → ❌ 진입 금지
자석구간 밖 + ★ + C2 위   → ✅ 추세 확인 후 진입
자석구간 밖 + ★ + C2 아래 (하단이탈) → ❌ 하락추세
```

**5. 8개 매수 시그널별 손절 기준 — 설명서에 없음**

```
BUY_URYANGJU / NONGSSA:  C2(노란선) 종가 이탈
BUY_SELYEOK:              C1 재하향 교차 (C1 < C2)
GONGJOONG:                구름대(S2) 이탈
NAKPOK:                   당일 저가 -3%
공통 안전망:               EMA200 종가 이탈 → 전량 청산
```

**6. 매도 4단계 — 설명서에 없음**

```
1차 익절(30~50%):  이격도 115% 돌파 시 (SHORT_PEAK ●)
2차 익절(20~30%):  E4선(VWMA8 × 1.3) 도달 시
포지션 축소:       MACD_BB_SELL ● 발생 시
전량 청산:         구름대(S2) 종가 이탈 시
긴급 손절:         EMA200 이탈 시 즉시 전량
```

**7. 4축 점수 체계(v2.0) — 설명서에 없음**

```
① 차트축  (0~34점): EMA정배열 +12 / DD<EMA20 +10 / DD·EMA20 동시돌파 +12
② 수급축  (0~33점): 기관/외국인/OBV/CMF
③ 테마/거래대금 (0~33점): 주도섹터 +20 / RVOL≥1.5 +13
④ 손익비 보너스 (+0~10점): DD손절폭 <2% → +10

S급(90↑) = 즉시 진입
A급(70~89) = 눌림 대기
B급(50~69) = 관망
PASS(50↓) = 진입 불가
```

**8. 섹터별 신뢰도 차등 — 설명서에 없음** 백테스트 실증 데이터 기준:

```
반도체장비(AMAT/KLAC/LRCX): BUY_SELYEOK → 10일 +14~19% ✅ 최우선
산업재(GE):                  BUY_URYANGJU → +3~5% (거래량 확인 필수)
금융(JPM/BAC):               BUY_SELYEOK 단독 → 신뢰도 낮음, GONGJOONG 동시에만
산업재(EMR):                 BUY_URYANGJU → -4.4% ❌ 비권장
```
