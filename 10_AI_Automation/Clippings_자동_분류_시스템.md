# Clippings 자동 분류 시스템

> Clippings 폴더의 파일을 Harness가 자동으로 분류하여 wiki 적절한 폴더로 이동하는 규칙

---

## 기본 원칙

### 1단계: Clippings에서 wiki로 이동
- Clippings에 파일이 추가되면 Harness가 자동 감지
- 파일 내용을 LLM이 분석하여 적절한 폴더 판단
- 파일은 **이동(move)** 방식으로 처리 (복사 아님)

### 2단계: INDEX.md 자동 갱신
- 대상 폴더의 INDEX.md에 링크 자동 추가
- 기존 링크는 Obsidian이 자동 인식 (파일 경로 변경 시 내부 링크 유지)

### 3단계: Clippings Archive 처리
- 처리가 완료된 파일은 `Clippings/Archive/`로 이동 (삭제 아님)

---

## 폴더 자동 생성 규칙

### 조건

기존 4개 폴더(00_Meta, 10_AI_Automation, 20_Research, 30_Journal) 어디에도 적합하지 않은 경우:

1. **새 폴더 필요 판단:** 파일 내용의 주제가 기존 폴더와 전혀 다른 경우
2. **최소 파일 수:** 해당 주제 파일이 3개 이상蓄積될 때 폴더 생성
3. **사용자 승인:** 폴더 생성 전 MJ님께 확인 요청

### 폴더명 형식

```
NN_카테고리명 (숫자2자리_한글명)
```

| 예시 | 의미 |
|------|------|
| `40_Law/` | 법학 자료 |
| `50_Finance/` | 금융/투자 자료 |
| `60_Tech/` | 기술 일반 |

### 번호 규칙

```
00_Meta        → 시스템 (가장 기본)
10_AI_Automation → AI/자동화
20_Research    → 연구/분석
30_Journal     → 일지/로그
40_~           → 사용자 정의 (MJ님 요청 시)
```

## 처리 흐름도

```
Clippings/신규파일.md
        ↓
  Harness가 파일 읽기
        ↓
  LLM이 내용 분석
  (키워드, 문맥 추출)
        ↓
  ┌─────────────────────┐
  │  기존 폴더와 매칭?   │
  └─────────────────────┘
    ↓ Yes         ↓ No
적절한 폴더로  ┌─────────────────────┐
이동 + INDEX   │  3개 이상 유사 파일? │
갱신          └─────────────────────┘
                   ↓ Yes        ↓ No
              새 폴더 생성    20_Research에
              요청 + 승인    일시 보관
                   ↓
           Harness가 폴더 생성
                   ↓
           파일 이동 + INDEX 갱신
```

## Clippings Archive 관리

| 상태 | 위치 | 설명 |
|------|------|------|
| **처리 대기** | `Clippings/` | Harness가 아직 처리하지 않은 파일 |
| **처리 완료** | `Clippings/Archive/` | wiki로 이동된 파일의 원본 저장 |

Archive 폴더는 백업 목적이며 Obsidian에서 관리하지 않음.

## 추가 고려사항: Office/PDF 파일 자동 변환

### 예정 기능

| 원본 형식 | 변환 도구 | 출력 |
|-----------|----------|------|
| Word (.docx) | python-docx + Pandoc | .md |
| Hangul (.hwp) | hwpx2txt 또는 별도 파서 | .md |
| PDF (.pdf) | marker-pdf 또는 pymupdf | .md |

### 미해결 질문: 변환 후 파일 이동

Clippings에서 Office/PDF 파일을 md로 변환한 후:

| 옵션 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **자동 이동** | Harness가 판단하여 적절한 폴더로 자동 분류 | 즉시 완료, 별도 작업 불필요 | 분류 오류 가능성 |
| **수동 이동** | 변환 후 MJ님이 직접 적절한 폴더로 이동 | 정확한 분류 보장 | 번거로움 |

**권장:**最初は 수동 이동, 분류 패턴 학습 후 자동 이동 전환

### 처리 순서 (예상)

```
Clippings/신규문서.pdf
        ↓
  Harness가 PDF 감지
        ↓
  markdown으로 변환 (marker-pdf)
        ↓
  ┌───────────────────────────┐
  │  이동 방식 선택            │
  │  (자동 또는 수동)          │
  └───────────────────────────┘
```
