## 결론 — CLAUDE.md를 새로 만들 필요 없음

**이미 다 있습니다.** 단지 Claude Code가 세션 시작 시 어떤 파일을 읽어야 하는지 알려주는 `CLAUDE.md` 하나만 만들면 됩니다. 내용은 새로 쓰는 게 아니라 **기존 파일들을 가리키는 포인터** 역할입니다.

```markdown
# CLAUDE.md (포인터 역할만 함)

세션 시작 시 아래 순서로 읽을 것:

1. ~/wiki/00_Meta/claude_briefing.md   ← 현재 시스템 상태 전체
2. ~/.hermes/constitution.local.md     ← 행동 규칙
3. ~/wiki/00_Meta/guardrails.md        ← 금지 행동
4. ~/wiki/00_Meta/USER.md              ← MJ님 프로필
```

`_meta.py`가 이미 `claude_briefing.md`를 최신으로 유지해주고 있으니 **이 구조면 충분합니다.**
