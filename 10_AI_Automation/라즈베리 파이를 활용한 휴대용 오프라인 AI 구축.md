이 변호사는 휴대용 오프라인 AI를 판매해 15만 달러를 벌었다. 이 AI는 법적으로 웹에 공개할 수 없는 문서를 분석한다. 전체 설정 비용은 50달러인데, 그는 이를 999달러에 판매한다. 단계별로 만드는 방법은 다음과 같다: 4가지가 필요하다: → Raspberry Pi 5 (8GB) → PiSugar 3 Plus 배터리 → 화면과 마이크용 Whisplay HAT → 64GB SD 카드. Ali에서 적절한 세일을 기다리면 총 비용은 약 50~90달러 정도다. 1. Raspberry Pi Imager를 사용해 SD 카드에 Raspberry Pi OS Lite 64-bit를 설치한다. 2. PiSugar 배터리를 Pi 아래에 쌓고, Whisplay HAT를 위에 끼우고, SD 카드를 삽입한 후 장치를 부팅한다. 3. 터미널을 열고 하나의 명령어로 Ollama를 설치한다: curl -fsSL [https://ollama.com/install.sh](https://t.co/5UVLVuIA5h) | sh 4. Pi에서 제대로 작동하는 모델을 가져온다: ollama pull phi3:mini 5. 모델을 실행하고 오프라인으로 대화를 시작한다: ollama run phi3:mini 전체 장치는 주머니에 들어가고, 배터리로 4시간 지속되며, 설정이 완료되면 인터넷을 전혀 사용하지 않는다. 이 변호사는 자신의 버전을 맞춤 케이스에 넣고, 법률 문서 분석 프롬프트를 미리 로드해 클라우드에서 고객 데이터를 법적으로 처리할 수 없는 로펌에 판매한다. 너는 의사, 회계사, 정부 계약자, 방위 산업 회사, 또는 건물 밖으로 데이터를 법적으로 내보낼 수 없는 다른 누구에게나 판매할 수 있다. 하드웨어 비용: 50~90달러. 판매 가격: 500~1999달러
