# 🗂️ 텔레그램 봇 칸반(Kanban) 사용 가이드

헤르메스 텔레그램 봇에 새롭게 추가된 **칸반(Kanban) 보드 기능**에 대한 안내입니다.
이 기능은 SQLite 데이터베이스(`~/.hermes/kanban.db`)를 기반으로 작동하며, 할 일(TODO), 진행 중(IN_PROGRESS), 완료(DONE) 상태를 직관적으로 관리할 수 있게 해줍니다.

## 🌟 주요 기능
- **명령어 및 인라인 버튼(Inline Keyboard) 지원**: 텍스트 명령어로 카드를 추가/이동/삭제할 수 있을 뿐만 아니라, 보드를 조회하면 나타나는 **인라인 버튼**을 눌러 아주 쉽게 카드를 이동하거나 삭제할 수 있습니다.
- **상태 관리**: `TODO` ➔ `IN_PROGRESS` ➔ `DONE` 3단계 칼럼 제공.

---

## 🛠️ 명령어 사용법

### 1. 보드 조회하기 (List)
```text
/kanban list
```
또는 단순하게 `/kanban` 만 입력하셔도 조회 방법 안내가 나타납니다.
- **결과**: 현재 등록된 모든 카드가 각 칼럼(TODO, IN_PROGRESS, DONE)별로 분류되어 나타납니다.
- **인라인 UI**: 카드 하단에 [Move to IN_PROGRESS], [Delete] 같은 클릭 가능한 버튼이 팝업되어, 휴대폰 터치만으로 쉽게 조작할 수 있습니다.

### 2. 새 카드 추가하기 (Add)
```text
/kanban add [할 일 내용]
```
- **예시**: `/kanban add 보고서 초안 작성하기`
- **결과**: `TODO` 칼럼에 새로운 카드가 고유 번호(ID)와 함께 즉시 생성됩니다.

### 3. 카드 상태 이동하기 (Move)
명령어로 수동 이동할 때는 아래와 같이 입력합니다. (인라인 버튼 클릭 시에는 이 과정을 자동 처리합니다.)
```text
/kanban move [카드 ID] [이동할 칼럼]
```
- **예시**: `/kanban move 3 IN_PROGRESS` (3번 카드를 진행 중으로 변경)
- **칼럼 이름**: `TODO`, `IN_PROGRESS`, `DONE` (대문자 필수 아님, 봇이 대문자로 자동 변환함)

### 4. 카드 삭제하기 (Delete)
```text
/kanban delete [카드 ID]
```
- **예시**: `/kanban delete 3` (3번 카드 삭제)
- **결과**: 해당 번호의 카드가 DB에서 영구 삭제됩니다.

## 📱 추천 워크플로우 (모바일/PC 공통)
1. 새로운 할 일이 생기면 생각나는 즉시 `/kanban add [내용]` 으로 추가합니다.
2. 현재 뭘 해야 하는지 궁금하거나 작업 상태를 변경할 때는 `/kanban list` 를 칩니다.
3. 텔레그램 화면에 뜬 각 카드의 **Move 버튼**을 톡톡 눌러서 상태를 변경하고, 완료된 작업은 **Delete 버튼**을 눌러 치워버립니다.
