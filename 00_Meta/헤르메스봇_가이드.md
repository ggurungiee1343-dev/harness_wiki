## 🪴 2. 핵심 자동화 가동 프로세스 (박사님 취향 저격)

### ① 지식 정원 가꾸기 (`/ingest`)
```
[Clippings/ 신규 파일] ➔ `/ingest` 명령 (또는 자연어 요청)
       ↓
[Gemma4 카테고리/제목 판단] ➔ `wiki/{카테고리}/{제목}.md`로 이관 생성
       ↓
[원본 대피 백업] ➔ `Clippings/Archive/` 폴더로 이동 (유실 방지)
       ↓
[Git Auto-Sync 발동] ➔ Git 백그라운드 자동 Commit & Push 완료
```

### ② 매일 새벽 3시 지능형 Dreaming 자동화
```
매일 03:00 (macOS launchd plist 타이머 가동)
       ↓
[dream_scheduler.py 백그라운드 호출]
       ↓
[HistoryManager 로드] ➔ `/Users/bluesea/.hermes/chat_history.json` 대화 수집
       ↓
[MemoryEngine.dream 실행] ➔ 대화 요약을 `wiki/00_Meta/hot.md`에 지능형 반영
       ↓
[Git Auto-Sync 발동] ➔ 백그라운드 클라우드 업로드 완료
```

## 🎮 3. 실전 명령어 매뉴얼

텔레그램 관제탑에서 박사님이 바로 쓸 수 있는 명확한 명령어 세트입니다.

*   **🪴 `/ingest`**
    *   **설명:** Clippings 내 신규 파일들을 옵시디언 위키로 이관 분류하고 원본은 `Archive/`로 백업한 뒤 Git 자동 커밋/푸시까지 원스톱으로 끝냅니다.
*   **🌙 `/dream`**
    *   **설명:** 최근 박사님과 주고받은 지속성 대화 이력을 바탕으로, LLM을 사용해 지능형 Dreaming 요약본을 만들어 `hot.md` 하단에 반영하고 자동으로 Git 클라우드 백업을 진행합니다.
*   **📊 `/status`**
    *   **설명:** 물리적인 macOS의 PhysMem 여유 상태를 진단하고 임계치 경고를 출력하며, 기존 `시스템 상태.md` 장부를 보고합니다. (0.3GB 미만 시 자율 치료 쉘 가동)
*   **🛡️ `/ask [질문 내용]`**
    *   **설명:** CoVe 팩트체크 기반 위키 교차 검증 답변을 생성합니다. (박사님의 요청에 맞춰 시간/단일 파일 조회 등 Fast 인텐트는 로딩 애니메이션 없이 즉각 사실 답변만 출력)
*   **⚙️ `/exec [명령어]`**
    *   **설명:** AI 자율 에러 수정 기능이 탑재된 Bash 쉘 명령어를 기동합니다.

## ⚡ 4. 헤르메스봇의 스크립트 "개발·수정 및 자가 리셋" 팁

헤르메스 봇은 단순 비서가 아닌 **스스로를 개조할 수 있는 코드 권한**을 지니고 있습니다.

1.  **스크립트 생성 및 수정 지시**:
    *   박사님이 "헤르메스봇, `Mjauto/Scripts/modules` 하위에 `xxx.py` 파일을 새로 생성하고 봇 `main()`에 연동해줘."라고 지시하면, 봇은 스스로 소스 코드를 설계하여 신규 생성하거나 기존 코드를 완벽히 리팩토링합니다.
2.  **자율 자가 리셋 (Self-Restart)**:
    *   코드가 수정된 직후, 봇에게 **자가 리셋**을 지시할 수 있습니다:
        > `오류 수정했으니 봇 서비스 리셋해줘` 또는 `/exec launchctl kickstart -k gui/501/com.bluesea.hermes_local`
    *   이 명령을 받으면 백그라운드 launchd 상의 구버전 봇이 강제 종료된 후, 새로 코딩된 최신 버전 봇이 1초 만에 깔끔하게 자율 기동됩니다. (Telegram 서버의 drop_pending_updates 세팅 덕분에 이전 대기 메시지 충돌 없이 부드럽게 재시작됩니다.)
