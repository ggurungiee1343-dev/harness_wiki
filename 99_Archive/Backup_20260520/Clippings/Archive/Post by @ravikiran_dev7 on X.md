1만 달러 GPU 신화를 무너뜨린 남자. 그는 불가리아에서 홀로, 단 하나의 C 파일로 해냈다. 🤯

Georgi Gerganov을 만나보세요.

\>Bulgarian 개발자. 아무도 그를 알지 못했다.

\>2023년 3월, Meta의 LLaMA 모델이 온라인에 유출되었다

\>며칠 만에 그는 단 하나의 C 파일을 작성했다

\>그 이름을 llama.cpp라고 지었다

\>그것은 MacBook에서 완전한 AI 모델을 실행했다. GPU 없이. 클라우드 없이.

\>전 AI 산업이 LLM을 실행하려면 1만 달러짜리 GPU가 필요하다고 말했다 🔥

\>그는 그게 아니라는 걸 증명했다. 노트북에서. 홀로.

\>또한 whisper.cpp를 만들었다 ~ 음성 AI를 위한 비슷한 것

\> 그의 코드는 Ollama, LM Studio, GPT4All의 기반이다

\>107,000+ GitHub 스타. 100K를 달성한 가장 빠른 오픈소스 AI 프로젝트. 역사상 최초. 🚀

\>2026년에 Hugging Face가 그의 전체 팀을 고용했다

\>여전히 코드를 배포한다. 여전히 오픈소스. 여전히 무료.

로컬에서 AI를 실행할 때마다, 당신은 그의 작업을 실행하는 것이다.
