박사님, 그동안 텔레그램 창에서 워낙 방대하고 혁신적인 아이디어들이 쏟아져 나와 복잡하셨을 만합니다. 출장 업무로 피로하신 박사님을 위해, 서울 기지(맥 스튜디오)에 복귀하자마자 순서대로 가볍게 해치울 수 있는 **'하네스 V2.5 자율 기지 구축 마스터 플랜'**을 딱 정리해 드립니다.
복사해서 하나씩 지워나가며 진행하시면 됩니다!
## 🏗️ [1단계] 기지 기초 공사 (인프라 및 보안 격리)
바이브 코딩 보안 체크리스트 1번 규칙에 따라, 시스템의 뼈대를 정식 구조로 개편하고 하드코딩된 API 키를 격리하는 작업입니다.
 * **자동 폴더 트리 생성**
   * 터미널을 열고 미리 만들어 둔 '디렉토리 자동 생성 스크립트'를 복사·붙여넣기 하여 마스터 컨트롤 룸(~/vps-agents/)과 5대 부서 격리 공간(~/srv/)을 한 번에 구축합니다.
 * **보안 격리 (.env 세팅)**
   * 기존 hermes_local.py 소스코드 내부에 적혀있던 텔레그램 봇 토큰과 외부 클라우드 API 키들을 새로 생성된 ~/.hermes/.env 파일로 옮겨 숨깁니다.
## 📂 [2단계] 소스코드 방 배정 (부서화 및 모듈화)
기존 파편화되어 있던 박사님의 소중한 스크립트 파일들을 정식 아키텍처 규칙에 맞게 제자리에 안착시키는 작업입니다.
| 파일명 | 기존 역할 | 이사 갈 정식 위치 |
|---|---|---|
| **hermes_local.py** | 텔레그램 관제탑 | ~/vps-agents/ (껍데기만 남겨 가볍게 유지) |
| **hybrid_router.py** | LLM 부하 라우터 | ~/.hermes/plugins/ 또는 skills/vllm/ |
| **system_monitor.py** | 리소스 모니터링 | ~/.hermes/cron/ (jobs.json에 5분 주기 등록) |
| **cognitive_engine.py** | 추론 및 요약 엔진 | ~/.hermes/skills/brain/cognitive/scripts/ |
| **wiki_manager.py** | 옵시디언 위키 관리 | ~/.hermes/skills/knowledge/wiki/scripts/ |
| **ingest_engine.py** | 외부 파일 자동 분류 | ~/.hermes/skills/gardening/ingest/scripts/ |
| **executor.py** | Bash 명령어 실행기 | ~/.hermes/skills/devops/executor/scripts/ |
## 🧠 [3단계] 지능 고도화 및 신규 스킬 장착
오픈소스 기술과 논문 검증 기법을 패키징 파일(SKILL.md) 형태로 에이전트의 뇌에 주입하는 단계입니다. 파이썬 코딩 없이 폴더에 집어넣기만 하면 됩니다.
 * **Meta CoVe(검증 사슬) 스킬 등록**
   * skills/cove_verifier/SKILL.md 파일을 생성하여 에이전트가 답변을 출력하기 전 [초안 ➔ 세부 질문 분할 ➔ 위키 교차 검증 ➔ 최종 수정] 단계를 거치도록 사고 회로를 제약합니다.
 * **오픈소스 ARS(학술 연구 스킬) 팩 설치**
   * 깃허브 레포지토리를 클론하여 전문적인 논문 설계, 피어 리뷰, 탐색적 대화 모드가 가능한 academic/ 부서 스킬 패키지를 통째로 이식합니다.
 * **CLI 코파일럿 스킬 추가**
   * skills/devops/cli-copilot/ 방을 파고 명령어 추천 지침을 넣어 GitHub Copilot CLI를 초월하는 로컬 터미널 비서를 활성화합니다.
## 🚀 [4단계] 코어 기능 업그레이드 (손가락 및 UI)
에이전트가 스스로를 고치고, 박사님이 사용하기에 가장 완벽한 사용자 경험(UX)을 완성하는 최종 단계입니다.
 * **자기 진화(Self-mutation) 유전자 이식**
   * 관제탑(hermes_local.py)에 파일 쓰기 모드('w')를 개방하여, 출장 중이거나 원격 상황일 때 에이전트가 스스로 소스코드를 재작성하고 부활할 수 있도록 손가락을 달아줍니다.
 * **인라인 버튼 UI 및 카운팅 기억 시스템 구축**
   * 텔레그램 BotFather 스타일의 그리드 버튼 인터페이스를 도입합니다.
   * 박사님이 /기억을 누르면 자주 쓰는 매크로가 버튼 리스트로 팝업되며, 클릭 시 즉시 실행과 동시에 사용 횟수가 카운팅됩니다. (30회 달성 시 영구 기억 저장소로 자동 증류 이관)
