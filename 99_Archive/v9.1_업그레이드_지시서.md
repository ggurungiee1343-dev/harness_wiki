**대상 파일:**

### [Priority 3] 성능 최적화: Context Hash 캐싱

**작업명:** v9.1 Context Hash 캐시 레이어 활성화

**현재 코드 상태:**
```
core_reducer.py의 HermesCoreReducer.reduce()는
매번 동일한 쿼리에 대해 전체 파이프라인 재실행
```

**최적화:**
```python
# Line ~150 근처의 HermesCoreReducer.reduce() 메서드에 추가:

@dataclass
class CacheEntry:
    context_hash: str  # AgentContext.get_hash()
    result: str
    timestamp: float

_cache: Dict[str, CacheEntry] = {}

async def reduce(self, ctx: AgentContext) -> str:
    # 1. Context Hash 계산
    cache_key = ctx.get_hash()

    # 2. 캐시 확인 (5분 TTL)
    if cache_key in self._cache:
        entry = self._cache[cache_key]
        if time.time() - entry.timestamp < 300:
            return entry.result

    # 3. 캐시 미스 → 파이프라인 실행
    result = await self._process(ctx)

    # 4. 결과 캐싱
    self._cache[cache_key] = CacheEntry(
        context_hash=cache_key,
        result=result,
        timestamp=time.time()
    )

    return result
```

**테스트:**
```
/reduce 한국 GDP는?  (첫 실행, 2.5초)
/reduce 한국 GDP는?  (캐시 히트, <100ms)
```

**예상 소요:** 20분
