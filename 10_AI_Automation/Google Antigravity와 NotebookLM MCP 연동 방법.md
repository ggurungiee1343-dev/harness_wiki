구글의 에이전트 중심 개발 플랫폼인 **안티그래비티(Google Antigravity)**와 **노트북LM(NotebookLM)**을 연동하기 위해서는 **MCP(Model Context Protocol)** 서버를 활용해야 합니다. 안티그래비티 내에서 외부 도구인 노트북LM의 기능을 에이전트(Agent)가 직접 호출할 수 있도록 연결해 주는 방식입니다.
인터넷상에서 널리 공유되는 핵심 연동법과 댓글의 팁을 종합한 구체적인 단계는 다음과 같습니다.
### 1단계: 노트북LM MCP 패키지 설치 (터미널 작업)
컴퓨터의 터미널(Windows의 PowerShell/CMD 또는 Mac의 터미널)을 열고, 노트북LM과 연동할 수 있는 오픈소스 MCP 패키지를 설치합니다. 파이썬(Python) 기반의 패키지 관리자를 이용하는 것이 가장 간편합니다.
 * **pip 사용 시:**
   ```bash
   pip install notebooklm-mcp-cli
   
   ```
 * **uv(빠른 파이썬 패키지 관리자) 사용 시:**
   ```bash
   uv tool install notebooklm-mcp-cli
   
   ```
### 2단계: 노트북LM 구글 계정 인증 및 로그인
설치한 도구가 내 노트북LM의 자료(노트북, 소스 등)에 접근할 수 있도록 구글 계정 로그인을 진행합니다.
 1. 터미널에 아래 명령어를 입력합니다.
   ```bash
   nlm login
   
   ```
 2. 명령어를 입력하면 자동으로 Chrome 등의 기본 브라우저가 열립니다.
 3. 현재 사용 중인 노트북LM의 구글 계정으로 로그인합니다.
 4. 로그인이 완료되고 터미널 창에 SUCCESS 메시지가 뜨면 브라우저 창을 닫아도 됩니다.
### 3단계: 구글 안티그래비티(Antigravity)에 MCP 서버 등록
이제 설치된 노트북LM MCP 도구를 안티그래비티 앱에 연결해 주어야 합니다.
#### 방법 A: 안티그래비티 UI 메뉴 활용
 1. 안티그래비티 앱을 실행합니다.
 2. 화면 우측 상단의 **... (더보기)** 메뉴를 누르거나, 에이전트 매니저(Agent Manager)에서 **Manage MCP Servers (MCP 서버 관리)** 메뉴를 클릭합니다.
 3. 연동 가능한 스킬/서버 목록에서 **NotebookLM**이 있는 경우 선택하여 설치(Install)를 진행합니다.
#### 방법 B: 설정 파일(mcp_config.json) 직접 수정 (추천)
UI에서 간혹 에러가 나거나 직접 등록하고 싶을 때는 설정 파일을 열어 텍스트를 추가해 줍니다.
 1. 안티그래비티의 MCP 서버 관리 뷰에서 **'View Raw Config' (원시 구성 보기)**를 클릭합니다.
   *(직접 경로로 찾아갈 경우 Windows/Mac의 ~/.gemini/antigravity/mcp_config.json 파일을 메모장 등으로 엽니다.)*
 2. "mcpServers" 항목 내부에 아래와 같이 노트북LM 설정을 추가하고 저장합니다.
```json
{
  "mcpServers": {
    "notebooklm-mcp": {
      "command": "notebooklm-mcp",
      "args": []
    }
  }
}

```
*(만약 실행 경로 문제가 생긴다면 command 부분에 설치 경로를 적어주거나, 패키지 가이드에 따라 uvx --from notebooklm-mcp-cli notebooklm-mcp 형태로 적어주시면 됩니다.)*
 3. 저장을 마친 후 안티그래비티의 MCP 관리 화면에서 **새로고침(Refresh)**을 누르면 notebooklm-mcp 서버가 활성화(Enabled) 상태로 바뀝니다.
### 4단계: 실전 활용 및 꿀팁
연동이 성공적으로 끝나면 안티그래비티 에이전트에게 대화(프롬프트)로 노트북LM의 기능을 명령할 수 있습니다.
 * **명령 예시:**
   * *"내 노트북LM에 있는 노트북 목록 다 보여줘."*
   * *"방금 수집한 이 웹페이지 URL(또는 PDF 파일)을 내 노트북LM에 소스로 추가해줘."*
   * *"노트북LM의 모든 소스를 종합해서 핵심 내용 3가지만 요약해줘."*
💡 **주의 및 팁 (댓글 내용 참고):**
 * **컨텍스트 윈도우 관리:** 노트북LM MCP는 약 35개 이상의 많은 도구(Tools)를 에이전트에게 제공하므로, 토큰(Context) 소모가 클 수 있습니다. 노트북LM 관련 작업을 하지 않을 때는 안티그래비티의 MCP 관리 창에서 해당 서버를 **Disabled(비활성화)**해 두는 것이 AI 모델의 효율을 높이는 데 도움이 됩니다.
 * **자동화 파이프라인 구축:** 안티그래비티에 **노션(Notion) MCP**도 함께 연결해 두면, *"안티그래비티로 웹 서치 ➡️ 노트북LM 소스로 저장 및 요약 ➡️ 요약본을 내 노션 페이지에 자동으로 기록"* 하는 완전 자동화 에이전트 파이프라인을 구축해 책 쓰기나 마케팅 리서치에 유용하게 쓸 수 있습니다.

노션 대신 **옵시디언(Obsidian)**을 쓰시는군요! 로컬 기반에 마크다운(Markdown) 형식을 사용하기 때문에, AI 에이전트와 연동했을 때 노션보다 훨씬 빠르고 강력한 나만의 지식 데이터베이스(PKM)를 구축할 수 있습니다.
안티그래비티와 노트북LM을 쓰면서 결과물을 옵시디언으로 바로 보내는 파이썬/Node 기반의 **옵시디언 MCP 서버 연동법**을 알려드릴게요.
## 🛠️ 옵시디언 MCP 연동 3단계
옵시디언은 로컬 프로그램이기 때문에, 안티그래비티(AI)가 내 컴퓨터 안의 옵시디언 금고(Vault)에 접근할 수 있도록 통로를 열어주어야 합니다. 가장 안정적인 방법은 **Obsidian Local REST API** 플러그인을 활용하는 것입니다.
### 1단계: 옵시디언 설정 (API 플러그인 설치)
 1. 옵시디언을 열고 **설정(Settings) ➡️ 커뮤니티 플러그인(Community plugins)**으로 이동합니다.
 2. 탐색에서 **Local REST API**를 검색하여 설치하고 활성화합니다.
 3. 플러그인 설정 화면으로 들어가면 **API Key**가 발급되어 있습니다. (이 키를 복사해 두세요.)
### 2단계: 안티그래비티 설정 파일(mcp_config.json) 수정
안티그래비티의 MCP 설정 창(View Raw Config)을 열고, 기존 노트북LM 설정 아래에 **옵시디언 MCP 서버 설정**을 추가합니다.
커뮤니티에서 주로 쓰이는 Node 기반의 공식/오픈소스 Obsidian MCP 설정을 예시로 들면 다음과 같습니다.
```json
{
  "mcpServers": {
    "notebooklm-mcp": {
      "command": "notebooklm-mcp",
      "args": []
    },
    "obsidian-mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-obsidian",
        "--api-key", "여기에_복사한_API_키_입력",
        "--vault-path", "C:/Users/사용자명/Documents/ObsidianVault"
      ]
    }
  }
}

```
> ⚠️ --vault-path에는 본인의 실제 옵시디언 금고(Vault)가 있는 컴퓨터 경로를 적어주셔야 합니다.
> 
### 3단계: 안티그래비티에서 연동 확인
설정을 저장하고 안티그래비티의 MCP 관리 화면에서 **새로고침(Refresh)**을 누르면 obsidian-mcp가 활성화됩니다. 이제 AI 에이전트가 내 옵시디언의 노트를 읽고, 쓰고, 수정할 수 있는 권한을 갖게 됩니다.
## 🚀 옵시디언 유저를 위한 추천 자동화 워크플로우
이제 안티그래비티에게 영어로든 한국어로든 아래처럼 자연스럽게 명령할 수 있습니다.
 * **자료 조사 및 자동 노트 생성:**
   > *"인터넷에서 최신 AI 트렌드를 검색하고, 노트북LM에 있는 내 기존 메모들과 비교해서 요약한 다음, 옵시디언의 Research 폴더에 2026-AI-트렌드.md 파일로 저장해줘."*
   > 
 * **데일리 노트 연동:**
   > *"오늘 노트북LM에서 요약한 책 핵심 내용을 내 옵시디언 오늘 자 데일리 노트 맨 밑에 추가해줘."*
   > 
마크다운 형식을 기가 막히게 잘 지켜서 저장해주기 때문에, 노션보다 가독성 높은 노트를 자동으로 쌓을 수 있습니다.
